## 2. 定版号

```powershell
# P31 改的是 public/（图标与遮罩样式），属于新增/修复且向后兼容 → 用 -Minor 或不带开关刷时间段
powershell -NoProfile -ExecutionPolicy Bypass -File set-version.ps1 -Minor
powershell -NoProfile -ExecutionPolicy Bypass -File set-version.ps1 -Check   # 必须无 WARN
```

> `version.json` 是派生文件，`set-version.ps1` 只告警不写；发版前按 `VERSION` 重生成一次根目录 `version.json`（发布包内的由 `make-release.mjs` 现生成）。

## 8. 回滚

| 场景 | 做法 |
| --- | --- |
| 包有问题 | 用上一版 `releases/LanTest-<旧版本>.zip` 覆盖部署目录（不动 `data/`） |
| 代码有问题 | `git revert <提交>` 或手动编辑恢复（契约 §7：不用 `git reset` 回滚线上） |
| 数据有问题 | 用 §6 的备份三件套整组覆盖回去，再重启 |
