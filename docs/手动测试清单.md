# 手动测试清单（真机点验用）

> 用法：每次有新批次验收通过，规划侧在这里**补行**；你按「优先级」挑着点。
> 记法：通过就写 `✓`，失败写 `✗` 并把**页面 + 步骤 + 实际看到的 + 期望的**四样发我；不适用的写 `—`。
> 口径：`必测` = 从没被真人在浏览器里确认过，且失败会明显影响使用；`抽查` = 我已在代码/接口层验过，只需你顺手看一眼。
> 关联列写的是产出批次，出问题我按批次定位提示词。

## 0. 开测前的准备

| # | 项 | 做法 |
| --- | --- | --- |
| P1 | 起服务 | 项目根目录 `node server.js`，浏览器开 `http://localhost:3000`；窗口保持打开能看到日志 |
| P2 | 账号 | 准备三样：**管理员** 1 个、**普通用户** 2 个、**游客**（不登录） |
| P3 | 两个浏览器 | 建议 Chrome + Edge（或 Chrome 普通窗口 + 隐身窗口），用来双人对打与观战 |
| P4 | 测试文章 | 至少一篇**短**（100 字左右，便于快速完赛）、一篇**长**（300 字以上，含换行与中英混排） |
| P5 | 改完代码后 | 先按 F5 强刷；若是 `server.js` 改动必须**重启** `node server.js`；只改 `public/` 的不用重启 |
| P6 | 记录方式 | 每条填 `✓ / ✗ / —`；`✗` 请附截图与浏览器控制台报错（F12 → Console 有没有红字） |
