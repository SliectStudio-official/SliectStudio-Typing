## 2. 验收（§6 二十条）

1. **模糊回来了**
   - 三卡、资料卡、链接组、通知面板计算值均为 `blur(20px) saturate(1.1)`：
     - `.dash-action`：`blur(20px) saturate(1.1)`（3 张相同）
     - `.dash-profile`：`blur(20px) saturate(1.1)`
     - `.dash-rows`（资料卡四行共用的玻璃组）：`blur(20px) saturate(1.1)`
     - `.home-notify-panel`：`blur(20px) saturate(1.1)`
   - CSS 同时声明 `-webkit-backdrop-filter: blur(var(--glass-blur-strong)) saturate(1.1)`；Chromium 的 `getComputedStyle` 对 prefixed 计算属性返回空串，故读数以未加前缀属性 + CSS 声明为准。
   - **A2/A3 冲突说明**：A2 让四条链接行都参与模糊，A3 要求非 none 元素 ≤6；逐行写会产生 3 卡 + 资料卡 + 4 行 + 通知面板 = **9**。本批把四条行放进 `.dash-rows` 一个玻璃上下文，实际计数 **6**，符合 A3；`.dash-row` 自身计算值为 `none`，视觉模糊由行组提供。若必须每行独立 `backdrop-filter`，需放宽 A3 到 9。
2. **模糊看得见**
   - 模糊生效：`docs/reports/P25.3-blur-on-1440.png`
   - 临时置 none：`docs/reports/P25.3-blur-off-1440.png`
   - 同一位置资料卡后的键盘纹理：开启时柔化，关闭时锐利。
3. **模糊没被流光盖掉**
   - 流光伪元素：`background: conic-gradient(..., var(--fx-ring-color) 330deg, ...)`，配合 `inset:0; padding:1px; mask: linear-gradient(...) content-box, linear-gradient(...); mask-composite: exclude`，只留下 1px 环；`::after` 的 hover 高光仅覆盖卡片内部一层低透明径向光，不是流光描边。
4. **匹配态背景色**
   - idle：`rgba(255, 255, 255, 0.05)`。
   - matching：`rgba(68, 74, 255, 0.2)`。
   - hover 规则：`background: var(--match-fill-hover)`，令牌值 `rgba(68, 74, 255, 0.28)`。
5. **匹配态描边**
   - `border-color: rgb(68, 74, 255)`；`border-width` 1px。
6. **匹配态文字**
   - 标题 `rgb(255, 255, 255)`、说明 `rgb(255, 255, 255)`；箭头 `display:none`，× `display:flex`。
7. **蓝色流光**
   - 匹配态 `--fx-ring-color=#444aff`，伪元素背景含 `rgb(68, 74, 255)`；idle `--fx-ring-color=#c96442`，伪元素含 `rgb(201, 100, 66)`。
8. **呼吸色**
   - 匹配态 `filter` 实测 `drop-shadow(rgba(68, 74, 255, 0.23) 0px 0px 3.2442px)`，来自 `fxBreath` 的 `var(--fx-ring-color)`。
9. **复位**
   - 取消后：背景 `rgba(255, 255, 255, 0.05)`、描边 `rgba(255, 255, 255, 0.11)`、标题 600/纯白、说明 400/`rgba(255,255,255,.62)`、箭头 `block`、× `none`、扫光 `display:none/animation:none`。
10. **性能**
    - `backdrop-filter` 非 none 元素数 **6**（三卡 + 资料卡 + `.dash-rows` + 通知面板）。
    - 真实 5 秒 rAF：301 帧，**P95=16.7ms**，最大 16.8ms；目标 ≤20ms。
11. **对比度**
    - 暗底 idle 卡片：白字 **18.57:1**，62% 次要文字 **7.54:1**。
    - 匹配蓝卡片：白字 **17.56:1**，次要文字（匹配态纯白）≥ **17.56:1**。
    - 资料卡：白字 **16.25:1**，次要 62% **7.01:1**；均 ≥4.5:1 / 3:1。
12. **回归**
    - 三卡纵向、铺满、主站字号不变：1440 下卡片 left 同为 `67.67`，top 依次 `433.61 / 529 / 624.39`；卡标题 16px；统计/版本仍由 mock 的 `/api/user/stats`、`/api/user/race-stats`、`/api/version` 填充。
13. **匹配态字重**
    - matching：标题 `700`、说明 `500`；取消后 `600` / `400`。
14. **× 尺寸**
    - `.dash-match-close` 为 `32px × 32px`，内部 svg 计算宽度 `16px`；× 中心 y `559.5`，计时标题中心 y `559.4`，**垂直差 0.1px ≤2px**。
15. **铃铛尺寸**
    - `.home-bell` `28px × 28px`，内部 svg `16px`；`.home-login` 高度 `28px`。
16. **扫光只在匹配时**
    - 进页面：`display=none`、`animationName=none`。
    - 点快速开始：`display=block`、`animationName=fxScan`。
    - 取消：`display=none`、`animationName=none`。
17. **扫光不挡点击**
    - 匹配态 `document.elementFromPoint` 命中卡片内部的 `svg` / `path`（快速开始图标），不是 `.fx-scan`；扫光 `pointer-events:none`。
18. **四条链接行左对齐**
    - 四行 `.dash-row-label` 的 `getBoundingClientRect().left` 均为 **1148.1px**（差 0）；`textAlign=left`。
19. **按钮类文字不居中**
    - `.dash-action` 三卡 `text-align:left`；`.dash-row` 四个按钮/链接 `text-align:left`；铃铛、状态条关闭、× 为纯图标按钮，无可居中文本；公告关闭为图标。
20. **资料卡其余排版**
    - 头像、昵称、统计：`textAlign=center`；`.dash-stats` 也为 `center`，四项统计未改为左对齐。
