## 二、插值与门控（代码路径核对）

| 检查 | 读数 |
| --- | --- |
| 插值条件 | `prev != null && delta > 0 && delta <= 12 && !completed` 才建动画；其余**直接落位**（含 `>12` 跳跃、`<=0` 回退） |
| 时长 | `t = min(1, (now - started)/300)`，线性推进 |
| 单循环 | `startMiniLoop()` 有 `if (state.miniRaf) return` 防重入；动画清空后 `cancelAnimationFrame` 语义收尾 |
| 只改显示 | 插值只调 `setMiniContent`，**不写** `p.progress`；名次与百分比仍由服务端数据计算 |
| 渲染预算 | `showMini && (i < 8 || 焦点)` —— 前 8 名 + 焦点 |
| 阶段门控 | `showMini = status === "racing"`；waiting/countdown 不渲染 |
| 完赛 | `target = content.length`，置灰显示尾段 + 「已完成 · 第 N 名」，不渲染光标 |
| 正文缓存 | `state.raceContent || r.content`，有 content 就缓存；缺失时 `setMiniContent` 显示「正在加载正文…」 |
