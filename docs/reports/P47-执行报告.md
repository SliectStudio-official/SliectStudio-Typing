## 三、停止点逐项确认

| 停止点 | 结论 |
| --- | --- |
| 1 所有行填满才完成 → 比赛能否结束 | 能。**实跑**（`tmp/p47-idle.out`）：房间 EF9X96 开局后故意留行不打、双方只 tick 一次即静默；+30s 仍 racing，**+91s 状态离开 racing 变 `cancelled`**，库内 `races` 行 `{status:"cancelled", cancelled_reason:"all_disconnected", finished_at:null}` —— 证明 cleanup 循环能结束无人完赛的局。**读码**（time_limit 分支需等 30–180 分钟，未实跑）：`server.js:1703` 超 `maxDurationMs` → `finalizeRoom(time_limit)`/`cancelRoom(duration_limit)`；`server.js:1711` 超 `charCount*2*60*1000` → `finalizeRoom(time_limit)`；cleanup 每 30s 一轮（`server.js:1727`） |
| 2 手机端软键盘 | 390×844 布局无溢出、各行可输入、自由跳行生效（读数见上）。**软键盘弹出/滚动跳动 headless 无法验证 → 未验证**，不声称支持；如真机异常再按提示词回退桌面端放开 |
| 3 R3 与行内选区删除冲突 | `shouldJumpBack` 要求 `selectionStart===0 && selectionEnd===0`，有选区一律走普通删除。实测：A2b 全选第 1 行 Backspace 只清空该行不回跳；C7 选末尾 3 字 Backspace 只删 3 字 |
| 4 观战迷你条是否复用引擎 | 不复用。`race.js` 里 `TypingEngine.create` 仅 1293 行一处；迷你条走 `setMiniContent`/`race-mini-*` 自绘（`race.js:1561` 附近），不经过引擎，无需同步改动 |
| 5 练习页缓存与 charStates 一致性 | 未硬改缓存结构。`updateSegmentStates` 的增量 diff 只触碰本行区间，`cachedCorrect/cachedWrong` 按旧状态减、新状态加，`prevInputLen` 按长度差增减，任意行编辑都自洽。A4/A4b/C4 的 wrong 归 0、正确率回 100 即为证据 |
