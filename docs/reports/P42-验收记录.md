## 一、静态

| 检查 | 读数 |
| --- | --- |
| `getRaceSettings()` 新增 key | `race_article_min_len` / `race_article_max_len`，默认 100/800 |
| 越界回落 | 非整数、<20、>2000、min≥max 一律回落 100/800 |
| 配对池过滤 | `content.length < settings.articleMinLen \|\| > settings.articleMaxLen`（原写死 100/800 已替换） |
| 优先区间 | `prefMin = max(200, minLen)`、`prefMax = min(400, maxLen)`；交集为空则全部 rank 0 |
| 池统计 | `getRaceArticlePool()` 用与配对**完全相同**的条件（approved + 字数范围 + 代码分类） |
| 前端 | `admin.html` 两个 number 输入框 + `#race-pool-hint`；`admin.js` 有 `renderRacePoolHint()`，加载与保存后都调用 |

## 二、接口实测（隔离副本 port 3280–3283）

| 请求 | 结果 |
| --- | --- |
