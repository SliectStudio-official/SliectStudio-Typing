## 五、方法留档（可复跑）

像素统计脚本 `tmp/pngink.cjs`（Node 内置 `zlib` 解 PNG + 反滤波 + 中位亮度阈值），用法：

```bash
node tmp/pngink.cjs <截图.png>            # 浅字于深底
node tmp/pngink.cjs <截图.png> dark-on-light   # 深字于浅底
```

这条方法已写进坑库 K-43：**叠层类 UI 验收必须量绘制结果**，光量 `getBoundingClientRect()` 会漏掉“被盖住但尺寸正常”的情况。
