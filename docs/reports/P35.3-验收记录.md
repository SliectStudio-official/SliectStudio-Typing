## 七、一处小瑕疵（不影响功能，下批顺手修）

`public/admin.js` 里「空分类标注」写死了分类名：

```js
const emptyNote = (c.name === '代码' && count === 0) ? '（空分类，可删除）' : '';
```

这违反 P35.2 定的「不得再按分类名比较」纪律（只影响显示，不影响判定）。建议下批改成**通用规则**：任何「不在 `codeCategoryIds` 里且文章数为 0」的分类都显示该标注，将来改名或新增空分类都不会失效。

## 八、给后续验收的一条经验

管理面板是**按导航懒加载**的：不点侧栏「文章管理」时列表就是 0 条、摘要「共 0 篇文章」，这不是缺陷。**验收必须先点对应区块再读数**（我第一轮就踩到，已复核）。建议记进坑库。
