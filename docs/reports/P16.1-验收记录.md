## 二、首页与引擎的代码口径

| 检查 | 读数 |
| --- | --- |
| `getSegmentStartOffset` | 已改为 `return segmentOffsets[segmentIndex] \|\| 0`，**不再累加段长** |
| 进度公式 | `pct = min(100, (getSegmentStartOffset(i) + inputValue.length) / originalText.length * 100)`，最后一段输满时直接 **100** |
| 错字上报 | 改为逐段配对：`base = segmentOffsets[si]`，`charStates[base + k] === "wrong"` → `expected_char: segment[k]`、`typed_char: value[k]`（不再用拼接串对齐原文） |
| 引擎 `offsetOf` | `return offsets[index] \|\| 0`，不再累加 |
| `splitTextWithOffsets` | 先调原分段函数，再按原文逐段对齐（游标 `cursor` 跳过空隙） |
| 累加残留 | 全仓搜 `offset += segments` / `off += segments` → **0 命中** |
| 单一实现 | 定义只在 `typing-engine.js`；`script.js` 无定义 |
