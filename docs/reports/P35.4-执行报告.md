## 1. 改了什么

在 `public/style.css` 的 `.code-input` 规则之后补 7 行：

```css
.code-input:focus,
.code-editor .code-input:focus {
  background: transparent;
  box-shadow: none;
  border: 0;
  outline: 0;
}
```

- **A1 特异性**：`.code-editor .code-input:focus`（0,2,1）高于全局 `textarea:focus`（0,1,1），无需 `!important`。
- **A2**：`grep` 检查 `textarea:hover` / `textarea:active` 无背景注入；只覆盖 `:focus` 即可。
- **A3**：未使用 `!important`。
- **A4 / A5**：未改 `.code-ghost`、行号、z-index 或任何 JS；比赛页共用同一套 `.code-input` 规则自动受益。
