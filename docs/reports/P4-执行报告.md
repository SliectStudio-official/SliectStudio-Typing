## 4. 不确定项

1. **Service Worker 旧缓存（K-13，超出本批）**：首次打开 `admin.html` 时，浏览器被旧 SW 控制的缓存 `admin.js` 仍执行了 XSS 负载（出现 `<img ...>`）。注销 SW、清空 CacheStorage、刷新 HTTP 缓存并 `ignoreCache` 重载后，加载当前代码，A 组验收全部通过。结论是代码已修，但既有客户端在 SW 缓存版本更新前仍可能跑旧 JS；K-13 已登记杂项批，本批未动。
2. **Node 版本**：执行机只有 v25.3.0，锁定的 22.14.0 未实测。
3. **管理员凭据**：沿用 P1 已批准的本地方式，以开发默认 JWT 密钥签发管理员 token 完成带凭据验收；未读取密码。生产密钥启动时该 token 无效。
4. **MySQL 分支**：未连 MySQL 实测；B1/B2 均为方言无关代码。
5. **数据库面板直写**：B1 只覆盖提示词指定的三个接口，通用 `PUT /api/admin/db/users/:id` 仍可写入非法邮箱（与提示词「B1 生效前此路仍允许」一致）；输出侧由 A1 转义兜住。
6. **数据面板翻页**：为验证多页临时创建 21 个 `__verify_page*` 用户，已全部删除；分页接口与 UI 均通过。
7. **`data-section` 选择器**：`admin.js:2100/2146` 用 URL hash 拼 `querySelector`，未做转义；非本批范围，未改。
