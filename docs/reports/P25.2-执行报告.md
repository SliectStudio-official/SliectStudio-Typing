## 2. 验收（按更新后的 §4，1–20 条）

1. **铺满无黑边**
   - 五档截图：`docs/reports/P25.2-1440x900.png`、`P25.2-1280x720.png`、`P25.2-1920x1080.png`、`P25.2-2560x1080.png`、`P25.2-3440x1440.png`。
   - `scrollWidth/clientWidth`：**1440/1440、1280/1280、1920/1920、2560/2560、3440/3440**。
   - 每张图的四角 + 四边中点共 8 点采样均**不是 (0,0,0)**；最暗值分别：1440 `(2,4,6)`、1280 `(1,4,6)`、1920 `(1,3,5)`、2560 `(2,4,7)`、3440 `(2,4,6)`。背景由照片 + 压暗层 + 网格/扫描线组成，无纯色空条。
2. **内容不裁切**
   - 五档上三卡容器与资料卡均满足 `left≥0 && right≤innerWidth && top≥0 && bottom≤innerHeight`：`inside=[true,true]`。
   - 1440：三卡 `[67.67,433.61,316.8,81]`…、资料卡 `[1112.33,359.41,260,420.19]`；2560：三卡 `[72,520.3,425,96]`…、资料卡 `[2168,465.25,320,428.09]`。

4. **竖屏仍列表**
   - 768×1024：`scroll=768/768`，动作区 **单列 736px**，三卡 `left=16` 相同、`top=177.8/265.8/353.8`；统计 2×2（`341.984px 341.984px`）；资料卡/版本都在视口内（bottom 938 / 970.8）。

5. **入场动画**
   - 三卡：`animation-name=fxEnter`，`animation-delay=0s / 0.08s / 0.16s`，`duration=0.24s`；资料卡 delay `0.24s`，版本 delay `0.30s`。
   - 总入场时长 **540ms**（最后一项 300ms + 240ms）≤600ms；首屏卡片在动画未结束时即可点击（测试在 250ms 点击快速开始成功进入匹配）。
6. **背景推近**
   - `animation-name=fxKenBurns`，`animation-duration=20s`，alternate 循环，`will-change=transform`。
   - 两次采样：`matrix(1.04015,...)` → `matrix(1.04069,...)`（不同）。
7. **网格/扫描线**
   - `.fx-grid`：`repeating-linear-gradient`，1px / 48px，白色不透明度 **0.05**；`.fx-scan`：`fxScan 8s linear infinite`，光带峰值不透明度 **0.045**。
   - 两者 `pointer-events: none`；截图可见极淡网格与横移光带。
8. **hover 流光**
   - hover 伪元素测试：`::before animation-name=fxBorderSpin`，`opacity=1`；测试页截图 `docs/reports/P25.2-hover.png`（为在无头截图中稳定展示，测试页用 `.fx-hover-preview` 强制同一条生产 hover 规则）。
9. **指针视差**
   - 左下：`--fx-tx=-3.92px`、`--fx-ty=1.77px`、`--fx-rx=-1.77deg`、`--fx-ry=-1.96deg`；右上：`3.95px / -1.91px / 1.91deg / 1.98deg`。幅度不超过 4px / 2°。
   - 绑定前检查 `matchMedia('(pointer: coarse)')`；触摸设备不启用。
10. **数字滚动**
    - 采样（从脚本启动计）：`81ms —`、`241ms —`、`321ms 0/0/0/0%`、`402ms 1/190/29/18%`、`482ms 1/329/50/31%`、`561ms 2/422/64/40%`、`881ms 2/527/80/50%`。600ms ease-out。
    - 无记录 `—` 不参与；版本号是带点号的非纯数字字符串，走文本加载/入场，不伪造数字。
11. **匹配态呼吸与光标**
    - 点击快速开始：`isMatching=true`、卡片 `animation-name=fxBreath`、标题伪元素 `fxBlink`、底部条 `is-visible=true`。
    - 卡内与底栏计时同源：`00:01 / 00:01`，`raceMatchPending=1`。
    - 匹配态强调色为蓝色：`--fx-accent=#444aff`；流光 conic-gradient 实测含 `rgb(68,74,255)`；呼吸 `drop-shadow` 同样使用该变量。截图 `docs/reports/P25.2-matching.png`。
    - 取消匹配：卡片 `isMatching=false`、`animation-name=none`（quickState classes `dash-action glass dash-quick fx-was-matching`）、底栏隐藏、强调色恢复 `#c96442`；不再重播 `fxEnter`。

    - 入场期间动画元素数 `getAnimations()=9`，远小于 60；空闲期只剩背景/扫描两条持续 CSS 动画。
13. **减弱动效**
