# 事故记录：比赛进度 ≥90% 时打字区整块消失（CSS 类名撞车）

> 发现于 2026-11-08 用户实测（`3.4` 线上），我先复现后定位。**这是阻断性缺陷，必须在下个补丁修掉。**

## 一、现象

比赛（代码素材局）打到 **142/157（≈90%）** 时，打字区整张卡片消失，只剩“文章 / 当前排名 / 我的进度”三张卡；此后键盘输入不再生效（进度停在 145）。用户原话：「又是输入到90%输入窗口就没了」。

## 二、我复现的过程（隔离副本 + 真实逐键输入，含 Enter）

| 时刻 | 读数 |
| --- | --- |
| 起跑 | `#race-typing` 高 313px、`.code-editor` 在、`.code-input` 有焦点、ghost 153 字符 |
| 打到 143 字符 | 一切正常：`boxH=313`、`.race-main` `display=block`、`activeElement=code-input` |
| **打到 145 字符（92.4%）** | **`boxH=0`**、`.code-stage` 0、`.race-main` **`display:none`**、`position:absolute`、`activeElement=BODY`（焦点丢了，所以后续按键无效） |

用 CDP `CSS.getMatchedStylesForNode` 拿到 `.race-main` 的命中规则，罪魁是这一条：

```text
.race-fx-sprint → position:absolute; display:none
```

## 三、根因：同一个类名既当“元素类”又当“状态类”

| 用途 | 位置 |
| --- | --- |
| ① 「冲刺」徽标元素 `<div class="race-fx-sprint" id="race-sprint">` | `public/race.html` |
| ② 徽标样式 `.race-fx-sprint { position:absolute; display:none; … }` | `public/style.css` 约 5058 行 |
| ③ 进度 ≥90% 时给 **容器的** 加同一个类：`main.classList.toggle('race-fx-sprint', active)` | `public/race.js` 第 1205 行（另 1117、1198 两处 remove） |
| ④ 本来只想给容器加个边框光效：`.race-main.race-fx-sprint { border-color…; box-shadow… }` | `public/style.css` 约 5065 行 |

因为容器自己也带上了 `race-fx-sprint` 类，②那条**通用**规则也命中容器，于是 `.race-main` 变成 `position:absolute; display:none` —— **整张打字卡被隐藏**。

注意：④的特异性更高（0,2,0）但它**没有声明** `display`/`position`，所以②的 `display:none` 依然生效。

## 四、为什么之前的“防御补丁”没挡住

P32-A 加的 `ensureTypingMounted()` 只在「`#race-typing` 里 `.char` 数量为 0」时自愈；这次 DOM 与字符都在（`chars=156`），只是**外层的 `.race-main` 被 `display:none`**，自愈逻辑不会触发。而且焦点被夺走，用户按键全部丢失。

这也解释了更早那次用户报的「打到一半比赛界面没有了」——同一个根因，只是当时没能复现。

## 五、修复方案（下批 P38）

| # | 做法 |
| --- | --- |
| 1 | **把状态类改名**：`race.js` 三处 `race-fx-sprint`（容器）→ `race-sprint-active`；CSS `.race-main.race-fx-sprint` → `.race-main.race-sprint-active`（含 reduced-motion 那条） |
| 2 | **把徽标规则作用域收窄**：`.race-fx-sprint { … }` → `.race-main > .race-fx-sprint { … }`；≤480px 那条同样处理 |
| 3 | 加一条防御：`.race-main { display: block; }` 不必加，改为在验收里断言「`race-main` 的计算样式里 `display` 永远不是 `none`」 |
| 4 | 全仓扫一遍同类问题：还有没有任何类名既作为元素类（HTML 里出现）又被 `classList` 加到容器上，列出清单 |

## 六、验收口径（关键三条）

| # | 判据 |
| --- | --- |
| 1 | 打到 **90% 与 100%** 两个时刻：`#view-race .race-main` 的 `display` 都是 `block`、`height > 200`（贴两个时刻读数） |
| 2 | 打字全程焦点不丢：`document.activeElement` 始终是 `.code-input`（贴 90% 时刻读数） |
| 3 | 能从 0 一直打到 **完成/结算**（贴结算界面读数），且「冲刺」徽标在 ≥90% 时仍正常显示（`#race-sprint` `display:inline-flex`） |
