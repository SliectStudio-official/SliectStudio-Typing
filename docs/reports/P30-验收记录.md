## 三、C 解散投票收口（这次实测最关键）

在隔离副本里建 2 人房，**让其中一人 62 秒不心跳**（旧阈值 45s 会判掉线），然后房主发起解散：

```text
62 秒后 dissolveRule → {"mode":"vote","needed":2,"online":2,"total":2}   ← 仍算两人在线
players offline 标记 → [false,false]
房主发起 → {"result":"voting","mode":"vote","needed":2,"online":2,"agreed":1}
快照 snap.dissolve → {"active":true,"needed":2,"agreed":1,"online":2,"myVote":"agree"}
```

也就是说：**你之前遇到的"显示要 2 人同意却直接解散"，现在不会再发生**——阈值 120 秒后，对手短暂不心跳不会被判离线；真要直解时也会明确告诉你「对手已掉线（最近心跳 N 秒前）」。

| 日志 | `[解散] start` 打点在 |
