## 1. 改了什么

### 1.1 服务端 `server.js`

| 位置 | 改动 |
| --- | --- |
| `getCodeCategoryIds()` | 读 `settings.code_category_ids`，解析数字数组并缓存；缺失/非法 JSON/非数组时返回 `[]` 并 `console.warn` |
| `setCodeCategoryIds(ids)` | 写回 JSON 字符串并清缓存；本批只提供函数，维护界面留给 P35.3 |
| `isCodeCategoryId(id)` / `isCodeArticle(article)` | 全站统一判定，禁止分类名比较 |
| `GET /api/code-categories` | 返回 `{ ids, categories }`，供练习页与比赛页加载语言筛选 |
| 排行榜 | 代码榜按 `a.category_id IN (codeIds)`；总榜/游客榜按 `NOT IN` 排除；`codeIds` 为空时代码榜 `1=0` |
| 快速匹配 `attemptMatch()` | `allowCode=false` 仅排除 `code_category_ids`；`allowCode=true` 优先代码池；候选行补 `isCode` |
| `createMatchedRoom()` / `/api/race/create` | 房间记录 `isCode`；`articleCategory` 保持语言/分类名 |
| `buildSnapshot()` | `race.articleCategory` 为语言名，`race.isCode` 为布尔值 |
| `/api/race/list` | 增加 `articleCategory`、`isCode` |
| 残留判定 | `grep` 确认 `server.js`/`public/*.js` 已无 `'代码'` 分类名比较（`NO_HARDCODED_CODE_COMPARISON`） |
