## 一、阻塞问题：真实库凑不出 3 篇候选，配对直接不发生

我在生产库副本上按真实流程跑了一次匹配：

```text
A join →  {"status":"waiting","waiting":1}
B join →  {"status":"waiting","waiting":2,"hint":"可用候选文章不足三篇，请稍后再试"}
A tick →  {}      （没有房间）
```

查库：

```text
status=approved 的文章共 3 篇，长度 72 / 245 / 281
200–400 字：2 篇     100–800 字：2 篇
```

P27 要求「3 篇互不相同」→ 永远凑不齐 → **点快速匹配只会一直转**。这是我的设计错误（提示词里我写死了 3 篇），执行方按规范实现。
