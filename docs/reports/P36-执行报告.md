## 6. 不确定项

1. **A3 与 A4 的取舍**：A3 要求展开/收起 160ms 过渡，A4/验收第 4 条要求点 × 后同一帧 `height=0`。实现为：展开与数据驱动收起走 160ms CSS 过渡；用户点公告 × 时由 JS 同帧把顶栏高度归零（满足 A4/第 4 条），视觉上 × 关闭是即时收起。
2. **无公告/公告失败**：`announcement-bar.js` 不提供事件，本批未改它；用 `MutationObserver` 监听 `style/class/childList` 判断可见性。请求失败时公告条保持 `display:none`，页面保持收起态（已用 Fetch 失败拦截实测）。
3. **沙箱公告测试数据**：验收时把沙箱公告 13 临时设为可关闭/启用/停用；生产公告未动，测试结束后沙箱服务已停止。
4. **3G 时间线**：用 CDP `Network.emulateNetworkConditions`（400ms 延迟、64KB/s、禁缓存）验证；时间线仅记录到 `DOMContentLoaded` 与 class 变更，不代表真实移动网络的首字节时间。
