## 4. 不确定项

1. **改密后旧 token 仍有效**：本批只做回查库，没有 token 版本号或改密失效机制；验收实测旧 token 仍 200。属 K-05 残留风险，后续批次处理。
2. **局域网无法首次初始化**：bootstrap 回环限制生效后，从局域网其它机器首次打开 `setup.html` 会被 403 拦住，必须在服务器本机完成初始化；这是拍板后接受的取舍。
3. **上线重登提示的口径**：本机验收使用新生成的文件密钥，旧开发密钥签发的 token 全部失效；生产若沿用 `launcher.config.ps1` 注入的同一 `JWT_SECRET`，理论上既有 token 仍可用，但按上线提示仍统一要求用户重新登录确认。
4. **Node 版本**：执行机只有 v25.3.0，锁定的 22.14.0 未实测。
5. **MySQL**：未连 MySQL 实测；本批改动均为方言无关代码，但回查库与计数器未在 MySQL 下跑过。
6. **初始化接口密码上限**：C4 的四处不含 `/api/bootstrap/create-admin`，该接口仍只校验至少 6 位（按提示词列表执行，未扩大范围）。
7. **限流状态在内存**：重启进程即清空失败计数；Map 10000 上限未实际压测。
8. **验收凭据方式**：管理员操作通过本地生成的 token 完成（从 `data/jwt-secret.txt` 读取密钥签名，写入 `tmp/`，全程未打印密钥）；前端页面未改，`admin.html` 改密 73 字节经由同一后端接口验证。
