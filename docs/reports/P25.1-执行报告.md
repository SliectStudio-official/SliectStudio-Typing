## 3. 怎么回滚

1. 将 `server.js` 的根路径文件名改回 `index.html`，`HTML_PAGES` 移除 `/home.html`，删除 `/assets/` 缓存分支。
2. 删除 `public/home.html`、`public/home.js`。
3. `public/nav.js` 两处 logo 改回 `<div class="logo">Typing</div>`。
4. `public/service-worker.js` 移除 `/home.html`、`/home.js`、`/announcement-bar.js` 的 precache 与 home 兜底。
5. `public/index.html`、`public/script.js` 恢复 P25 版本（`16472a3^`）；或按提交 `16472a3` 反向编辑。

不涉及数据库结构、`data/`、`VERSION`、`CONTRACT_VERSION`。
