## 4. 不确定项

1. **既有 `/api/user/stats` 500（非本批引入）**：profile 页调用该接口返回 500。路由 SQL 只有一个 `?`（user_id），却传了 `req.user.id, days` 两个参数，better-sqlite3 抛「Too many parameter values」。P10 只改 CSS，按冻结清单未改 `server.js`；建议后续批次单独修复（删除多余参数或调整占位符）。因此「控制台无报错」这一条受该既有问题影响，字体资源本身无报错。
2. **打字输入元素**：`.typing-line-text` 主文本仍为等宽 16px；`.typing-line-input` 的 computed 在改动前后均为 system-ui 14px（既有行为，未受本批影响）。
3. **字体回退**：中文回退依赖系统字体（Windows 微软雅黑 / macOS PingFang / Noto Sans SC）；computed 栈已包含三者，未引 Web 字体。不同系统实际字形会有差异，但家族栈与字号/字重/字距一致。
4. **截图缺失**：内置浏览器可视区域不可见，未取截图；以上用 computed 的 family/size/weight/letter-spacing 对比完成视觉回归。
5. **版本状态（P10 范围外）**：执行期间规划侧把 `VERSION` / `CONTRACT_VERSION` 升到 `3.0.261106.2038` / `v2`，生产库 `settings.schema_version` 已同步为 `v2`，与代码一致；P10 页面验收使用早期 v1 副本的 tmp 实例，字体改动与版本真值无关。
