## 2. 怎么验证（已真跑）

1. 打开 `design/index.html` → 点「快速开始」：卡片变蓝、出现倒计时、底部滑出状态条；再点卡片或点状态条 ×：复位。
2. CDP 自动验收（`node tmp/cdp-verify.cjs`，本机实测）：
   - 点卡片后 `is-matching=true`、状态条 `is-visible=true`、倒计时卡与状态条同步（`00:14 | card: 00:14`）；
   - 点整张卡片 → `is-matching=false`、`is-visible=false`；
   - 重新开始后点状态条 × → 同样复位。
3. 动画采样（`node tmp/cdp-anim.cjs`）：`transform` 从 `translateY(75px)` 收到 `0`，`opacity` 0→1，
   实测采样 `0ms:75px/0 → 80ms:17.2px/0.60 → 160ms:3.63px/0.94 → 240ms:0.49px/1 → 400ms:0.0009px/1`。
4. 像素对照：把 Figma 官方 1x 渲染图与 1920×1080 截图做 difference 叠加
   （`tmp/diff-home.png`、`tmp/diff-matching.png`），两张画板都只剩字体抗锯齿差异，无位移。
