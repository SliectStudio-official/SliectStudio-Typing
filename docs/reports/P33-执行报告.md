## 2. 怎么验证

```bash
node --check server.js
node --check public/admin.js
powershell -NoProfile -ExecutionPolicy Bypass -File set-version.ps1 -Check

cd tmp/p33-app && PORT=3095 node server.js

# 鉴权
curl -i -X POST http://localhost:3095/api/admin/backup/create -H 'Content-Type: application/json' -d '{}'
curl -i http://localhost:3095/api/admin/backup/list
# 默认备份
curl -s -X POST http://localhost:3095/api/admin/backup/create \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{}'
# 列表 / 下载 / 恶意名 / 删除
curl -s http://localhost:3095/api/admin/backup/list -H "Authorization: Bearer $TOKEN"
curl -s -D - -o /tmp/b.zip http://localhost:3095/api/admin/backup/download/<name> -H "Authorization: Bearer $TOKEN"
curl -s --path-as-is http://localhost:3095/api/admin/backup/download/%2e%2e%2fdb-config.json -H "Authorization: Bearer $TOKEN"
curl -s -X DELETE http://localhost:3095/api/admin/backup/<name> -H "Authorization: Bearer $TOKEN"
# 恢复排队 / 取消；改 server.js 后重启进程
curl -s -X POST http://localhost:3095/api/admin/backup/restore -H "Authorization: Bearer $TOKEN" -F 'file=@<name>.zip'
curl -s -X POST http://localhost:3095/api/admin/backup/restore/cancel -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{}'
```

页面：`/admin.html#backup`（创建 / 列表 / 下载 / 恢复 / 删除 / 420px / pending 横幅）。

## 6. 不确定项

1. **pre-restore 文件名/白名单**：pre-restore 备份命名为 `backup-YYYYMMDD-HHMMSS-<VERSION>-pre-restore.zip`，下载/删除白名单另外允许受控的 `-pre-restore` 后缀；与 P33 提示词中给出的单一正则不完全字面一致（否则 pre-restore 备份无法下载/删除）。恶意路径仍全部 400。
2. **MySQL**：在线备份/恢复只对 SQLite 实现；MySQL 返回 400，未启动 MySQL 实例实测。
3. **列表“含配置”**：为不反复解 ZIP，列表读取 `<zip>.meta.json` sidecar；若手动删除 sidecar，列表显示“否”，ZIP 内 manifest 仍为准。
4. **删除确认截图**：原生 `confirm` 是浏览器级弹窗，截图只能截页面本体；另用 CDP `Page.javascriptDialogOpening` 捕获确认原文 `确定删除备份 …？此操作不可恢复。`，截图见 `C13-delete-confirm-page.png`。
5. **生产 3000**：验收时本机 3000 端口无进程；读数来自隔离端口 3095，部署时必须重启 `server.js`。
