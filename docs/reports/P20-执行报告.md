## 2. 怎么验证

### 2.1 §4 十三条逐条读数

#### 1. 加入表单

浏览器读取：

```text
hasCheckbox = false
body.innerText.includes('以观战身份加入') = false
```

`public/race.html` 中已删除 `join-spectator` 节点，`race.js` 中无该元素读取。

#### 2. 大厅「观战」按钮

公开房间行读数：

```text
2/8 人 · 281 字 · 房主 __p20_host · 观战 0/1
[加入] [观战]
```

点击「观战」（密码弹窗输入 `1234`）后：

```text
mySeat = spectator
players = [__p20_host, __p20_p1]
spectators = [__p20_p2]
#room-players = [__p20_host 房主 未准备, __p20_p1 未准备]
#spec-list = [__p20_p2]
#spec-actions = [你正在观战, 回到选手席]
```

选手列表不出现外部观战者。

#### 3. 容量（8 人房）

| 请求 | 状态 | 响应 |
| --- | --- | --- |
| `settings {seats:2}` | 400 | `{"error":"观战席位数必须在 1 到 1 之间"}` |
| `settings {seats:1}` | 200 | `{"success":true,"enabled":true,"mode":"free","seats":1,"cap":1}` |

按 R2/R3：8 人房 `floor(0.8)=0`，夹到 1，实际恒为 1 席。

#### 4. 自助进席（free）

普通玩家 p1 点击「进入观战席」：

```text
self = { success:true, seat:"spectator", spectatorSeats:1, spectatorCount:1 }
tick = { mySeat:"spectator", players:1, spectators:1 }
页面 = [__p20_host 房主 未准备, __p20_p1 观战中]
room-status = 等待所有人准备（0/1）
```

`spectatorCount` +1、选手席 -1、已准备分母从 2 变 1；点「回到选手席」后返回 `mySeat:"player"`、`players:2`、`spectators:0`，`ready` 为未准备。

#### 5. 房主进席

房主点击「进入观战席」：

```text
tick = { mySeat:"spectator", isHost:true, players:1, spectators:1 }
页面 = 开始比赛按钮 display:block
p1 ready 后 = startDisabled:false, room-status:"全员已准备，房主可以开始"
```

房主观战状态下实际点击开始：

```text
tick = { mySeat:"spectator", isHost:true, status:"countdown" }
view-room = none, view-spectate = block
spec-audience = 观战 1/1 · 你正在观战：__p20_host
```

点「回到选手席」后 `mySeat:"player"`，恢复准备/选手状态。

#### 6. host 模式

```text
mode = "host"
普通玩家页面 #spec-actions = "观战席位由房主安排"，按钮数 = 0
POST /api/race/spectate/self {action:"enter"} → 400 {"error":"观战由房主安排"}
外部观战 join → 400 {"error":"本房间观战需房主安排"}
```

#### 7. 房主指定

```text
assign {targetType:"user",targetId:p1,to:"spectator"} → 200 {seat:"spectator", count:1}
p1 tick = mySeat:"spectator", players:1, spectators:1
assign {targetType:"user",targetId:p1,to:"player"} → 200 {seat:"player", count:0}
p1 tick = mySeat:"player", players:2, spectators:0
```

两次 `mySeat` 与计数均改变；前端房主行也有「转观战 / 回选手席」按钮，点击走同一 assign 接口。

#### 8. 开赛后

房主 spectator、p1 选手、房间进入 `countdown` 后：

| 请求 | 状态 | 文案 |
| --- | --- | --- |
| `settings` | 400 | `比赛已开始，不能换席` |
| `self` | 400 | `比赛已开始，不能换席` |
| `assign` | 400 | `比赛已开始，不能换席` |

观战者页面：

```text
view-spectate = block
#spec-audience buttons = 0
#spec-board rows = 2
```

选手页面左栏只读观战块：

```text
观战 1/1 人
__p20_p1
```

#### 9. 无选手开局

房主进入观战席，房间选手数为 0：

```text
POST /api/race/start → 400 {"error":"没有选手，无法开始"}
```

#### 10. 观战席位满

席位数 = 1，已有外部观战者时，普通玩家再进席：

```text
POST /api/race/spectate/self {action:"enter"}
→ 400 {"error":"观战席已满（1/1）"}
```

#### 11. 关闭观战

房主在 UI 取消「开放观战」：

```text
before: toggle=true, count="1/1", list="__p20_p2 回选手席"
after:  toggle=false, count="0/0", list="暂无观战者", note="观战已关闭"
p2 /api/race/active = { code:null }
外部观战 join → 400 {"error":"本房间未开放观战"}
```
