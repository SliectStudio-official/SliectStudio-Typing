代码素材一键导入 · 使用说明
================================

【这个工具做什么】
给你的站点补上“代码模式”所需要的数据：
  · 3 个语言分类：JavaScript / Python / SQL
  · 5 篇代码素材：JS-数组求和、JS-函数与默认值、PY-字典排序取前二、PY-逐行解析带异常、SQL-按速度分组取名次
  · 设置项 code_category_ids（把上面三个分类标记为“代码语言分类”）

重复运行是安全的：已存在的分类和素材会自动跳过，不会重复插入。

【前置要求】（全部满足才能跑通）
  1. Windows 系统（本站只支持 Windows 部署）
  2. 项目已经启动过至少一次 —— 也就是项目目录下有 data\typing.db
     （服务启动时才会建表；空目录直接跑本工具会提示“库还没初始化”）
  3. 项目目录下有 node_modules\better-sqlite3（装过依赖）
  4. 机器上有 Node.js（本站本来就是 Node 跑的，一般都有）
  5. 不需要联网、不需要登录、不需要管理员权限

【怎么用】
  方式一（推荐）：
    1) 把本压缩包里的两个文件（这个说明 + .bat + seed-code.cjs）
       解压到【项目根目录】（和 server.js 同一层）
    2) 在面板里先停掉服务
    3) 双击 “一键导入代码素材.bat”
    4) 看到“导入完成”后按任意键关闭，再回面板启动服务
    5) 浏览器 Ctrl+F5，去练习页切「代码模式」看看

  方式二：
    解压到任意位置双击 .bat，按提示把项目根目录拖进窗口回车即可。

【怎么确认成功】
  · 练习页 → 切到「代码模式」→ 下拉能看到 5 篇素材
  · 比赛 → 建房 → 出现「代码房间」标签
  · 管理页 → 代码模式管理 → 语言分类 → JavaScript / Python / SQL 三个开关为打开状态

【报错怎么办】
  “没找到项目目录”       → 把工具解压到项目根目录，或按提示拖入项目路径
  “库还没初始化”         → 先用面板启动一次服务（自动建表），停服务后再跑本工具
  “独占数据库 / SQLITE_BUSY”→ 面板里停掉服务再跑
  “没找到 Node.js”       → 在提示里填 node.exe 的完整路径

【它不会动什么】
  · 不删除、不修改你已有的文章、用户、成绩
  · 不改任何表结构
  · 只做两件事：加分类/素材，写一个设置项
