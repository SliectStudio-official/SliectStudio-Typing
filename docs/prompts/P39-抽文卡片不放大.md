# P39-匹配抽文：轮转期间所有卡同尺寸，抽完只有中奖卡放大居中（含代码局）

> 读的提示词就是本文件。开工时算本文件 sha256，写进执行报告第一行。
> 你是执行方 AI。改 `public/style.css`（缩放规则）、`public/race.html`（给副标题加 id）、`public/race.js`（定格时改文案）。**不用重启。**

## 0. 用户要的效果（原话）

> 「我说的是刚开始随机的动画中了的卡就放大了 而且被选中的卡是放大后居中展示。。。」
> 「未被选中时所有卡都一样大小 随机动画播放完毕后被选中的才会放大居中展示」

也就是：

| 阶段 | 期望 |
| --- | --- |
| 轮转（`系统正在为你抽取文章`） | **所有卡完全一样大**，只靠描边/发光表示“正在点这张” |
| 定格（抽完） | **只有中奖卡放大 + 居中**，其它卡变小变暗或淡出 |

## 1. 现在为什么不对（我核过代码）

| 位置 | 现状 | 问题 |
| --- | --- | --- |
| `style.css` 约 5635 `.race-reveal-item` | 入场 `translateY(20px) scale(.94)` | 卡片先被缩小，聚拢时再放大到 1.05 |
| 约 5638 `.is-gathered` | `scale(1.05)` | 与高亮态不一致 |
| **约 5640 `.is-highlight`** | **`scale(1.06)`** | **轮转时被点到的那张会放大 → 看起来像已经选中了** |
| 约 5645 `.is-winner` | `translateX(var(--reveal-shift)) scale(1.15)` | 这个是对的（放大 + 居中），保留 |
| `race.html` `.race-reveal-sub` | 固定文案「系统正在为你抽取文章」，**没有 id，JS 改不了** | 定格后卡片已经放大居中，文案却还写着“正在抽取” → 用户以为“随机中途就放大了” |

## 2. 要改什么

### A 轮转期间：所有卡同尺寸

| # | 选择器 | 改成 |
| --- | --- | --- |
| A1 | `.race-reveal-item`（约 5629） | `transform: translateY(20px)`（去掉 `scale(.94)`） |
| A2 | `.race-reveal-stage.is-gathered .race-reveal-item` | `transform: translateY(0)`（去掉 `scale(1.05)`） |
| A3 | `.race-reveal-stage .race-reveal-item.is-highlight` | `transform: translateY(0)`（**去掉 `scale(1.06)`**，只保留 `border-color` 与 `box-shadow`） |

### B 定格：只有中奖卡放大 + 居中（保留现状，不放大改动）

| # | 选择器 | 要求 |
| --- | --- | --- |
| B1 | `.is-winner` | **保留** `translateX(var(--reveal-shift,0px)) scale(1.15)`；再补一层柔和阴影 `0 12px 32px rgba(0,0,0,.3)` 强化层级 |
| B2 | `.is-single .is-winner` | 保留 `scale(1.12)` |
| B3 | `.is-leaving .is-winner` | 离场时**不再额外放大**：把 `scale(1.25)` 改成 `scale(1.15)`（与定格一致）+ 淡出 |
| B4 | `@media (max-width:768px)` 三条 winner 规则 | 保留 `1.02` / `1.04`（移动端小放大即可） |
| B5 | `.is-out`（未中奖退场） | 保留 `scale(.82)` |

### C 文案跟着状态走（这是“看起来像随机中途放大”的真正原因）

| # | 要求 |
| --- | --- |
| C1 | `race.html` 里 `<div class="race-reveal-sub">` 加 `id="race-reveal-sub"` |
| C2 | `race.js` 在**中奖卡定格**（加 `is-winner` 的同一时刻）把副标题改成 **`已抽中：<文章标题>`**；`is-single` 分支改成 **`已选中：<文章标题>`** |
| C3 | 轮转期间仍显示 `系统正在为你抽取文章`；进入 `is-leaving` 时可改成 `即将开始…`（可选） |
| C4 | 不改文案以外的任何时序（轮转 120ms、定格 1500ms 保持不变） |

## 5. 停止点

- 若去掉高亮缩放后，用户完全看不出“正在抽哪张” → 停，先报，我同意你给高亮态加**非缩放**强调（更亮的描边/双层发光）；
- 若代码局卡片因标题过长在放大后溢出舞台（`overflow:hidden` 裁切）→ 停，先报截图，我决定是否给标题加 `text-overflow` 或缩小放大倍数；
- 若中奖卡居中依赖缩放后的宽度（去掉高亮缩放后偏移量不对）→ 停，先报，我决定是否动 `--reveal-shift` 计算。
