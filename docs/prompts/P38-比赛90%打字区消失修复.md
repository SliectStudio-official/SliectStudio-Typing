# P38-比赛 90% 打字区消失（CSS 类名撞车，阻断性缺陷）

> 读的提示词就是本文件。开工时算本文件 sha256，写进执行报告第一行。
> 你是执行方 AI。**只改 `public/race.js` 与 `public/style.css`**（约 10 行），**不用重启**（只改 `public/`）。
> 这是线上阻断缺陷，优先做。

## 0. 根因（我已复现并定位）

`race-fx-sprint` 这个类名被用在两个地方：

| 用途 | 位置 |
| --- | --- |
| ① 「冲刺」徽标元素 `<div class="race-fx-sprint" id="race-sprint">` | `public/race.html` |
| ② 徽标样式 `.race-fx-sprint { position:absolute; display:none; … }` | `public/style.css` 约 5058 行 |
| ③ 进度 ≥90% 时给**容器** `.race-main` 加同一个类 | `public/race.js` 第 1205 行 `main.classList.toggle('race-fx-sprint', !!active)`（另 1117、1198 两处 `remove`） |
| ④ 只想给容器加边框光效 `.race-main.race-fx-sprint { border-color…; box-shadow… }` | `public/style.css` 约 5065 行 |

结果：容器带上 `race-fx-sprint` 后也命中②那条通用规则 → **`.race-main` 变成 `position:absolute; display:none`，整张打字卡消失**，焦点丢失，之后按键无效。

我的实测：打到 **145/157（92.4%）** 时 `#race-typing` 高度从 313 → **0**、`.race-main` `display:none`、`document.activeElement` 从 `.code-input` 变成 `BODY`。

## 1. 要改什么

| # | 要求 |
| --- | --- |
| A1 | **状态类改名**：`public/race.js` 里三处给容器用的 `race-fx-sprint` 全部改成 `race-sprint-active`（1205 的 `toggle`、1117 与 1198 的 `remove`） |
| A2 | **CSS 跟着改名**：`.race-main.race-fx-sprint` → `.race-main.race-sprint-active`（含 `prefers-reduced-motion` 里那条） |
| A3 | **徽标规则收窄作用域**：`.race-fx-sprint { … }` → `.race-main > .race-fx-sprint { … }`；`@media (max-width: 480px)` 里那条 `.race-fx-sprint` 同样收窄 |
| A4 | 全仓扫一遍同类隐患：找出「既作为元素类出现在 `race.html`/`index.html`，又被 `classList` 加到容器上」的类名，列成清单写进报告（已知 `race-fx-combo`、`race-fx-overtake` 只作为元素类，不动） |
