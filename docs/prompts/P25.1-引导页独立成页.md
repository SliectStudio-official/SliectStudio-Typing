# P25.1-修正：引导页独立成页，并作为站点默认页

> 读的提示词就是本文件。开工时算本文件 sha256，写进执行报告第一行。
> **上一批我做错了**：用户的设计稿是**单独一页引导页**，我让你塞进了 `public/index.html`。本批推翻重做。

## 0. 用户原话（就是需求，照做）

> 「完全可以复制我的设计稿改一改作为 xxx.html，网站默认打开这一页，然后里面才是交互，引导页我怎么设计的就怎么呈现，只在最上面显示通知，并且正常的顶层栏点击 typing 字样是打开引导页」

拆成六条硬要求：

| # | 要求 |
| --- | --- |
| U1 | **复制设计稿改一改**成独立文件 `public/home.html`（不是重画，是搬过来改成能接数据的真页面） |
| U2 | **网站默认打开引导页**：访问根路径 `/` 看到的是 `home.html` |
| U3 | **交互在引导页里**：三张卡片（继续上次的练习 / 快速开始 / 加入比赛房间）就在这一页操作 |
| U4 | **引导页照设计稿原样呈现**：布局、留白、字号、玻璃、图标一个不改 |
| U5 | **最上面只显示通知**：不要整套导航条，只保留通知（公告 + 铃铛） |
| U6 | **顶层栏点「Typing」字样打开引导页**：其它页面上的站点名变成回引导页的入口 |

## 4. 顺手修掉 P25 留下的真缺陷（K-39）

背景图放在 `public/assets/`，但**现有指纹只覆盖 `public/` 根目录的 js/css**，而 `express.static` 给静态资源设 `maxAge: 7d`。以后换图，用户最长 7 天看老图。

| # | 要求 |
| --- | --- |
| E1 | 给 `/assets/` 单独设 `Cache-Control: public, max-age=0, must-revalidate`（局域网 304 代价可忽略）；不动其它目录缓存头 |
| E2 | 或者给图片 URL 拼 `?v=<哈希>`。二选一，报告说明选了哪个与原因 |

## 7. 停止点

- 若还原 `index.html` 时发现 P25 之外还有别的改动混在同一文件 → **停**，先报差异清单，不许凭猜还原；
- 若通知抽屉强依赖 nav 的 DOM 结构 → **停**，先报两种方案（引导页自带轻量面板 / 复用 nav 但只渲染通知部分）；
- 若 `?article=` 入参会影响打字引擎初始化顺序 → **停**，先报影响面；
- 若根路径改指 `home.html` 会打破现有任何跳转（例如 `nav.js` 里大量指向 `index.html` 的链接）→ **逐个列出**再改，别一刀切。
