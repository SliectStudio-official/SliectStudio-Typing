# P10-字体统一为系统默认（去衬线）

> 读的提示词就是本文件。开工时把本文件 sha256 算出来，写进执行报告第一行。
> 你是本项目的执行方 AI。开工前读 `AGENTS.md` 的 §0、§5、§7，再读 `docs/CURRENT.md` 五块。
> 本批只做一件事：把全站标题的衬线字体换成系统默认无衬线，**不动字号、字重、字距**。

## 0. 上一轮不确定项的处理决定

| 不确定项 | 决定 | 理由 |
| --- | --- | --- |
| 是否保留衬线用于装饰 | 不保留，全站去衬线 | 用户 2026-11-07 明确要求「改为系统默认字体，不要衬线体」 |
| `--font-mono`（打字区等宽）是否一起改 | **不改** | 它是功能性的（对齐字符、判断错字），换掉会影响判定与排版 |
| 模块归属 | 只动 `public/`（public-pages 模块），不碰 `server.js` | 纯样式改动 |

## 1. 冻结清单

| 项 | 值 |
| --- | --- |
| 允许改动的模块 | `public/style.css`、`public/index.html`、`public/admin.html`、`public/profile.html`、`public/setup.html` |
| 允许的依赖 | 不新增；不引 Web 字体、不加 `@font-face` |
| 允许的新文件 | `docs/reports/P10-执行报告.md` |
| 不再允许触碰 | 任何 `.js` 文件、`server.js`、`service-worker.js`、`manifest.json`、`VERSION` |

## 2. 逐项交付

现状（已核实）：

| 位置 | 现状 |
| --- | --- |
| `public/style.css:50` | `--font-display: Georgia, 'Times New Roman', serif;`（被 15 处 `var(--font-display)` 使用） |
| `public/style.css:51` | `--font-body: system-ui, -apple-system, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, 'Noto Sans', sans-serif;` |
| 四个 HTML 的内联 `:root` | 各自重复定义了同样三组字体变量（含 Georgia 衬线） |
| `public/setup.html:39` 与 `:131` | 两处直接写死 `font-family: Georgia, 'Times New Roman', serif;` |

| # | 交付物 | 改法 |
| --- | --- | --- |
| F1 | 消掉衬线变量 | 把 `--font-display` 改成 **`var(--font-body)`**（引用同一个变量，不再各自维护一份栈） |
| F2 | 中文回退补全 | 在 `--font-body` 的 `sans-serif` 之前插入 `'Microsoft YaHei', 'PingFang SC', 'Noto Sans SC'`，避免不同浏览器回退到不同中文字体 |
| F3 | 四个 HTML 内联 `:root` | 与 F1、F2 同步改（`index.html`、`admin.html`、`profile.html`、`setup.html`） |
| F4 | `setup.html` 两处写死的 Georgia | 改成 `var(--font-body)` |

硬约束：**只改 font-family 相关声明**。font-size / font-weight / letter-spacing / line-height / 颜色 / 布局一律不动——那会让「换字体」变成「改设计」，回归面立刻爆炸。

## 3. 验收口径

| 步骤 | 期望 |
| --- | --- |
| 全仓检索 `Georgia|Times New Roman` | **0 处** |
| 全仓检索非 sans 的 serif | 0 处（注意 `sans-serif` 本身保留，检索时排除） |
| `public/style.css` 里 `--font-display` 的定义 | 只有一个 `var(--font-body)`，没有第二份字面量栈 |
| 浏览器打开 `index.html` 的导航 logo 与 `admin.html` 的栏目标题 | DevTools Computed 面板的 `font-family` 首项为 `system-ui`（或 Windows 上的 Segoe UI），**不含 serif**；标题与正文家族一致 |
| 打字练习页 | 打字区仍是等宽字体（`--font-mono` 未变）；字符对齐、错字高亮、光标位置与改动前一致 |
| 中文+英文+数字混排（如公告、用户名、文章标题） | 无方框、无「有的字是衬线有的不是」的混排 |
| 视觉回归 | 三个页面的标题字号/字重/字距与改动前一致（只换家族）；截图或列出 Computed 的 font-size/weight/letter-spacing 三组值做前后对比 |
| 控制台与资源 | 无 404、无报错；`style.css` 的 `?v=` 指纹已随内容变化（P5 机制自动），客户端一次刷新即生效 |

命令示例：

```powershell
Select-String -Path public\*.css,public\*.html -Pattern 'Georgia','Times New Roman'
(Select-String -Path public\style.css -Pattern '--font-display').Line
```

## 4. 停止点

- 发现除上述位置外还有写死的其它字体族（例如某个 `@font-face` 或内联 `font-family`）→ 先报清单，不要顺手改
- 换字体后出现字符错位、行高跳变、按钮文字溢出 → 停（说明有地方隐式依赖了衬线的字宽）
- 需要改 `.js` 文件或调整布局 → 停

## 5. 交付格式

四段式加执行报告，写进 `docs/reports/P10-执行报告.md`，第一行写 `docs/prompts/P10-字体统一为系统默认.md` 的 sha256。报告必须含：改动前后 `--font-display` / `--font-body` 两行原文、检索结果（0 处）、三个页面的 Computed font-family 与 font-size/weight 对比、不确定项。

## 6. 本轮不做

- 不动字号/字重/字距/行高/配色/布局（这是换字体，不是改版式）
- 不动 `--font-mono` 与打字区相关样式
- 不引 Web 字体、不加 `@font-face`、不改 `service-worker.js` 的预缓存清单（指纹机制已自动处理）
- 不做 P9 的任何一项（那是另一批）
