## 1. A 件：补齐 PWA 图标（不生成二进制，用 SVG）

| # | 要求 |
| --- | --- |
| A1 | 新建 `public/icons/icon.svg`：256×256 视口，品牌色 `#f54e00` 圆角方块（圆角 56）+ 白色键盘/字母「T」图形；纯手写 SVG，不引外部资源、不嵌位图 |
| A2 | `public/manifest.json` 的 `icons` 改为指向 `/icons/icon.svg`，`"type": "image/svg+xml"`、`"sizes": "any"`、`"purpose": "any maskable"`；删掉两条 png 声明 |
| A3 | 五个页面（`home.html` / `index.html` / `race.html` / `profile.html` / `admin.html`）的 `<head>` 加 `<link rel="icon" type="image/svg+xml" href="/icons/icon.svg?v=<指纹>">`；指纹走现有 `?v=` 机制（`public/icons/` 不在根目录，若指纹表只覆盖根目录 js/css，则本文件不加 `?v=`，改为在服务端给它 `Cache-Control: no-cache` 或 `max-age=300`，二选一并在报告里说明选了哪个） |
| A4 | `service-worker.js` 的 `CRITICAL_ASSETS` 增加 `/icons/icon.svg` |
| A5 | 不新增二进制文件、不引 npm 包；若你判断必须给 PNG（某些浏览器不认 SVG 图标），**停**，先报，我另批 |
