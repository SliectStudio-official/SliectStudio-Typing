## 1. 要做的事

### 1.1 房间码一键复制（等待厅）

| # | 要求 |
| --- | --- |
| A1 | 等待厅 `#room-code` 旁加一个复制按钮（图标或「复制」小字，24×24 点击区 ≥32×32），点击复制**6 位房号** |
| A2 | **复制实现顺序**：先试 `navigator.clipboard.writeText`；`navigator.clipboard` 不存在或抛错时，回退到 `document.execCommand("copy")` + 临时 `textarea`（`position:fixed; opacity:0`，用完立刻移除） |

| A4 | **只复制房号，不复制密码**（密码是房主创建时自己输入的，不在客户端留存） |
| A5 | 键盘可达：按钮 `type="button"`、`aria-label="复制房间码"`、Tab 可聚焦 |
