## 2. B 件：历史战绩（新功能）

### 2.1 服务端：一个只读端点

`GET /api/user/race-history?page=1&limit=10`（需登录，未登录 401）返回：

| 字段 | 说明 |
| --- | --- |
| `items[]` | 每场一条：`raceId / code / articleTitle / charCount / status / playerCount / rank / speed / accuracy / timeSeconds / finishedAt / startedAt / cancelledReason / finished`（`finished` 表示本人是否完赛） |
| `summary` | 与 `/api/user/race-stats` 一致的 `{ racedCount, finishedCount, winCount, winRate, bestRank }` |
| `pagination` | `{ page, limit, total, totalPages }` |

| # | 要求 |
| --- | --- |
| B1 | 查 `race_participants` JOIN `races`（`WHERE rp.user_id = ?`），按 `races.started_at DESC, races.id DESC` 排序；只返回**已开始过**的房间（`started_at IS NOT NULL` 且 `races.status` 属于 finished / cancelled / racing） |
| B2 | 只读；不改表、不改 `CONTRACT_VERSION`；`limit` 夹在 1–50、默认 10 |
| B3 | `rank / speed / accuracy / timeSeconds` 取本人那一行；掉线未完成的场次 `finished=false`、`rank=null` |
| B4 | 只查 `user_id` 匹配的行，不得把其他玩家或游客的数据带出来 |

### 2.2 前端：历史战绩面板

| # | 要求 |
| --- | --- |
| B5 | 表格列：日期时间 / 文章 / 名次 / 速度 / 正确率 / 用时 / 状态；名次列显示「第 N 名」或「未完成」，状态列显示「已结束 / 中途退出 / 已解散」 |
| B6 | 顶部四格汇总：场次 / 胜率 / 最佳名次 / 完赛场次（取 `summary`）；无数据时显示 `0 / — / — / 0` |
| B7 | 分页与练习历史同款交互，每页 10 条 |
| B8 | 空态：「还没有比赛记录，去比赛大厅开一局」+ 跳 `race.html` 的按钮 |
| B9 | 速度取整（`Math.round` 字/分）、正确率整数 %、用时保留 1 位小数 |
| B10 | 宽度 ≤420px：表格变**卡片式**（每场一小卡：日期 + 文章 + 名次 + 速度），不横向滚动 |
