# P18.3-匹配底栏重做（跟随主题 + 时间居中加粗 + 关闭图标）

> 读的提示词就是本文件。开工时算本文件 sha256，写进执行报告第一行。
> 你是执行方 AI。用户实测：暗色模式下底部匹配条是**亮底 + 白字**，几乎看不清；且要求「时间居中加粗、取消按钮在时间右侧、用关闭 SVG」。本批只改这条底栏。

## 0. 缺陷与根因

| 现象 | 根因（`public/style.css:4339` 起） |
| --- | --- |
| 暗色主题下底栏是亮色背景 + 白色文字，可读性极差 | `.race-match-bar { background: var(--ink); color: #fff; }` —— **把"文字色令牌"当背景色用**。`--ink` 在亮色主题是 `#141413`（深），在暗色主题是 `#e8e6e0`（浅），于是暗色下变成"浅底 + 白字" |
| 时间靠左、字重普通、取消按钮贴最右 | `.race-match-bar { justify-content: space-between; }` + 文字无 `font-weight` |
| 取消是文字按钮 | `.race-match-bar-action` 里 `textContent = '取消'` |

## 1. 要求

### A 组：样式跟随主题（`public/style.css`）

| # | 要求 |
| --- | --- |
| A1 | 底栏改用**表面类令牌**，不再用 `--ink` 做背景：`background: var(--glass-bg)`、`color: var(--ink)`、`border-top: 1px solid var(--hairline-soft)`、`box-shadow: var(--glass-shadow)`，并加 `backdrop-filter: blur(var(--glass-blur))`（含 `-webkit-` 前缀） |
| A2 | 布局改为**居中**：`display:flex; align-items:center; justify-content:center; gap:10px`，即「时间 +（间距）+ 关闭图标」作为一组整体水平居中 |
| A3 | 时间 `font-weight: 700`、`font-variant-numeric: tabular-nums`（跳秒不抖动）、颜色 `var(--ink)` |
| A4 | 关闭按钮：**26×26 圆形**、`border: 1px solid var(--hairline-strong)`、`background: transparent`、`color: var(--body-strong)`；hover 时 `background: var(--glass-bg-hover); color: var(--ink)`；内部 SVG `stroke: currentColor`、14×14 |
| A5 | 两种主题都必须可读：亮色下深字浅底、暗色下浅字深底；**禁止任何写死的 `#fff` / `#000` 背景或文字色**（本组涉及的选择器内） |
| A6 | 底栏高度改为**由脚本写入变量**：JS 用 `document.body.style.setProperty('--race-match-bar-h', bar.offsetHeight + 'px')`，`body.race-match-open { padding-bottom: var(--race-match-bar-h, 54px) }`，避免换行/换字号后遮挡内容 |
| A7 | 420px 下：内边距收紧、字号 12.5px、关闭按钮仍 26×26 可点（不小于 24px） |

### B 组：标记与交互（`public/nav.js`）

| # | 要求 |
| --- | --- |
| B1 | 底栏标记改为：`<div class="race-match-bar" id="race-match-bar"><span class="race-match-bar-text" id="race-match-bar-text"></span><button class="race-match-bar-close" id="race-match-bar-action" aria-label="取消匹配" title="取消匹配"><svg viewBox="0 0 16 16" fill="none" stroke-width="1.6" stroke-linecap="round"><path d="M4 4l8 8M12 4l-8 8"/></svg></button></div>` |
| B2 | **不得再往按钮里写文字**：现有 `els.action.textContent = actionLabel \|\| '取消'` 会抹掉 SVG。改为只更新 `aria-label` 与 `title`（等待态「取消匹配」），并保留图标 |
| B3 | 三种状态的文案/按钮：① 等待：「匹配中 mm:ss」+ 关闭图标；② 匹配成功且**自动跳转**：「匹配成功，正在进入比赛…」（无按钮）；③ 匹配成功但**用户在练习中**：「匹配成功」+ 主按钮「进入比赛」+ 关闭图标 |

| B5 | 键盘可达：关闭按钮可 Tab 聚焦、Enter/Space 触发；`Esc` 不关闭底栏（避免误取消匹配），但「取消」必须显式点击/回车 |
| B6 | 保留原有行为：取消 → 调 `/api/race/match/cancel`、清 `raceMatchPending`、收起底栏、移除 `body.race-match-open` |

## 2. 验收（逐条贴读数）

| # | 场景 | 判据 |
| --- | --- | --- |
| 1 | 亮色主题匹配 | 底栏 `background-color` 为浅色令牌、`color` 为深色；对比度 ≥ 4.5:1（贴出两色与计算值） |
| 2 | 暗色主题匹配 | 底栏为深色令牌、文字浅色；对比度 ≥ 4.5:1（贴读数）；**不允许出现浅底白字** |
| 3 | 居中 | 读 `#race-match-bar-text` 与 `#race-match-bar-action` 的 `getBoundingClientRect()`：两者组成的一组，其水平中点与视口中点偏差 ≤ 2px |
| 4 | 加粗 | 时间元素 `computedStyle.fontWeight = 700`（或 ≥600），且秒数变化时宽度不变（`tabular-nums` 生效：贴两次不同秒数的宽度） |
| 5 | 关闭图标 | 按钮内是 `svg`、无文字节点；`aria-label="取消匹配"`；点击后 `status` 变 `idle`、底栏 display none、`raceMatchPending` 清空 |
| 6 | 三态 | 分别截图/读数：等待态、自动跳转态、练习中手动进入态（含「进入比赛」主按钮） |
| 7 | 不遮挡 | 底栏出现后 `body` 的 `padding-bottom` 等于底栏 `offsetHeight`（贴两个数值）；420px 同样成立 |
| 8 | 键盘 | Tab 能聚焦关闭按钮，Enter 触发取消 |
