# P34-代码模式（VSCode 式输入框 + 独立代码榜）

> 读的提示词就是本文件。开工时算本文件 sha256，写进执行报告第一行。
> 你是执行方 AI。**原型已经在 `design/code-mode-prototype.html`（我写的，直接用浏览器打开可交互）**，你要做的是把它搬进站点并接上文章/榜单。
> 用户补充口径（2026-11-08，**优先级高于下文所有描述**）：① **复用现有练习界面**，不许新建页面/路由，也不许做全屏遮罩式练习区；② **比赛可以勾选是否允许匹配代码模式**；③ **自建房可以任意选择**（含代码文章）；④ 代码榜独立。
> 用户口径：「窗口显示的得是正确代码的格式 可以辅助用户打缩进 但是回车不帮助 就做类似 VSCode 的输入框」「代码独立为代码榜」。

## 0. 先看原型（务必先打开它敲一遍）

| 项 | 说明 |
| --- | --- |
| 文件 | `design/code-mode-prototype.html`（单文件、无外部依赖、内联 CSS/JS） |

| 你不需要 | 重新设计交互。**行为照原型，视觉可换成站点自己的设计令牌** |

## 1. 组件（前端）

| # | 要求 |
| --- | --- |
| A1 | 新建 `public/code-typing.js`：把原型里的引擎部分（状态机、比对、Tab/Enter、统计）抽成可复用组件，暴露 `createCodeTyping(container, { text, onChange, onFinish })` 与 `destroy()` |
| A2 | **不改 `typing-engine.js`**；普通文章继续走现有引擎。代码模式与普通模式互斥，同一时刻只有一个挂载 |
| A3 | 视觉接到站点令牌：字体 `ui-monospace`，已输入正确用 `var(--ink)`，错误用 `var(--semantic-error)`，待输入 `rgba(107,114,128,.45)`（暗色主题下适配），背景用 `var(--canvas)` / `var(--surface)` |
| A4 | **两层对齐铁律**：ghost 层与 `textarea` 的 `font-family / font-size / line-height / letter-spacing / tab-size / padding` 必须用**同一组值**（建议集中写成一个 CSS 类，两处共用）；`textarea` 文字透明、`caret-color` 可见 |
| A5 | 宽度不足时**横向滚动**（不折行），光标所在位置自动滚动到可见区（`scrollIntoView({inline:"nearest",block:"nearest"})` 或等价做法） |
| A6 | 空格在待输入状态显示为 `·`（灰），已打对后变亮；这样缩进可见 |
| A7 | 禁粘贴与拖放（`paste` / `drop` 一律 `preventDefault`），复制粘贴不能绕过 |
| A8 | 自动补齐的字符（Tab 补的缩进、Enter 带出的缩进）**标记为 assisted**：视觉上略淡（`--muted` 蓝调），**不计入击键与准确率分母**；「显示辅助字符」调试开关只在 `?debug=1` 时出现 |
| A9 | 完成判定：输入长度达到原文长度即结算；结算卡片复用现有结构，标题加一行小字「代码模式」，不新增金币/特效 |
| A10 | 打字过程中任何异常都要 `try/catch` 并 `console.error("[代码模式] ...", e)`，**不许留半成品界面** |

## 2. 入口（复用现有练习界面，**不新增页面**）

## 5. 验收（逐条贴读数）

| # | 场景 | 判据 |
| --- | --- | --- |
| 1 | 与原型一致 | 同一篇素材分别在原型与站点里打 12 个正确字符：两边 `.ch-ok` 数、进度、准确率一致（贴两组数字） |
| 2 | 错误显示 | 打 3 个错字符：错误红显、波浪线、错误次数 3、准确率按「正确/已输入」算（贴读数） |

| 5 | 禁粘贴 | 复制一段代码后 Ctrl+V：内容不进入输入框（贴输入前后长度） |

## 7. 停止点

- 若在站点里做到「与原型一致」需要改站点全局字体或行高 → **停**，先报（可能影响其它页面）；
- 若总榜排除代码成绩会让现有数据统计口径变化（例如管理面板的今日成绩）→ **停**，先报影响面；
- 若把原型搬过来发现 textarea 与 ghost 始终对不齐（不同浏览器差 1–2px）→ **停**，报你试过的对齐方案，不要用 `transform` 硬凑；
- 若有人主张代码模式也进比赛池 → **不做**，本批明确不进（用户已定）。
