# P44-通知中心显示全部公告 + 头像未读徽章

> 读的提示词就是本文件。开工时算本文件 sha256，写进执行报告第一行。
> 你是执行方 AI。改 `server.js`（公告接口返回多条）、`public/nav.js`（头像徽章 + 打开即读）、`public/style.css`（徽章样式）。**做完必须重启。**

## 0. 用户反馈

> 「通知中心只有一个通知　公告显示可以保持现状　而且有通知的话要给用户头像上也显示一个徽章　防止用户不知道」

现状与原因：

| 现象 | 根因 |
| --- | --- |
| 发了两条公告，通知中心只看到一条 | `server.js:725 getActiveAnnouncement()` 有 `LIMIT 1`，且 `/api/notifications` 只 push 这一条 |
| 用户不打开头像菜单就不知道有通知 | 未读徽章 `#notify-badge` 只挂在**菜单项「通知中心」**里，头像上没有任何提示 |

期望：**顶部橙条保持现状（仍只显示优先级最高的一条）**；**通知中心列出全部生效公告**；**头像右上角显示未读徽章**。

## 1. 服务端（`server.js`）

| # | 要求 |
