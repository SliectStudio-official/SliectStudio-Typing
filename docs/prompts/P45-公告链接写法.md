## 0. 需求（用户已拍板）

> 「只支持 [文字](URL)，编辑器加一个插入链接的按钮跟提示」

| 项 | 决定 |
| --- | --- |
| 写法 | **只支持** `[文字](URL)`；**不**自动识别裸 URL、**不**支持其它 Markdown（粗体/换行/图片一律当文本） |
| 生效位置 | 顶部公告条、通知中心条目、首页铃铛面板、管理页公告预览（四处同一套渲染） |
| 点击行为 | 新标签打开：`target="_blank"` + `rel="noopener noreferrer"` |
| 数据 | 仍是纯文本存库，**不改表结构、不改接口、不加依赖** |

## 1. 新增文件：`public/announce-text.js`（唯一实现，约 30 行）

| # | 要求 |
| --- | --- |
| A1 | 暴露全局 `window.AnnounceText = { render: function (el, text) { ... } }`；**不要**用 innerHTML 拼字符串 |
| A2 | 解析正则：`/\[([^\]]{1,200})\]\(([^)\s]{1,500})\)/g`；按匹配位置切分片段 |
| A3 | 普通片段一律用 `document.createTextNode`（天然转义） |
| A4 | 链接片段：**URL 必须**匹配 `^(https?:\/\/)` 或 `^(\/[^\s]*)$`（站内相对路径）才创建 `<a>`；否则**整段当纯文本**原样输出（例如 `[坏链](javascript:alert(1))` 必须显示成这串字，且 DOM 里没有 `<a>`） |
| A5 | 链接元素：`el.href = url`、`el.textContent = 文字`、`el.target = '_blank'`、`el.rel = 'noopener noreferrer'`、`el.className = 'announce-link'` |
| A6 | 容错：未闭合的 `[`、空文字 `[](...)`、`text` 为 null/空 → 全部按纯文本输出；不抛异常 |
| A7 | 先清空容器（`el.textContent = ''`）再逐段 append |

## 2. 页面引入（**顺序很重要**：必须在使用它的脚本之前）

## 4. 管理页：插入链接按钮 + 写法提示

| # | 要求 |
| --- | --- |
| C1 | `public/admin.html` 公告编辑区（公告内容 textarea 附近）加按钮 `<button type="button" class="admin-btn" id="announcement-insert-link">插入链接</button>`；按钮下方加提示行：`支持链接写法：[点这里](https://example.com)，点击后在新标签打开`（灰色小字，复用现有 `.admin-hint` 风格） |
| C2 | 若无选中文字 → 在 `announcementMsg` 提示「请先在公告内容里选中要变成链接的文字」，**不发请求、不改内容** |
| C3 | 有选中文字 → `prompt` 让用户填 URL（默认值放 `https://`）；用户取消则什么都不做 |
| C4 | URL 校验：必须 `^(https?:\/\/)` 或 `^(\/[^\s]*)$`；不合法则提示「链接必须以 http:// 或 https:// 开头，或以 / 开头的站内路径」，不改内容 |
| C5 | 用 `setRangeText` 或等价方式把选中文字替换成 `[文字](URL)`，替换后光标停在 URL 结尾并让 textarea 重新获得焦点（用 selectionStart/selectionEnd） |
| C6 | 若没选中但光标处有文本 → 不自动猜，仍提示先选中（保持行为可预期） |

## 5. 样式（`public/style.css`）

| # | 要求 |
| --- | --- |
| D1 | `.announce-link` 通用：`color: inherit; text-decoration: underline; text-underline-offset: 2px` |
| D2 | 顶部公告条内（橙/红底白字）：链接必须保持可读 —— `text-decoration: underline` 且 `color: inherit`，hover 时稍微降低不透明度 |
| D3 | 长链接不能撑破布局：公告条文本容器若原本单行，保持单行 + 省略；通知中心条目允许换行（`word-break: break-word`） |
| D4 | 暗色主题下链接不要变成默认蓝色（用 `color: inherit`） |

## 8. 停止点

- 若 `nav.js` 里 body 那格是和标题/时间拼在同一个 innerHTML 字符串里（改造会牵动较多），先把该段代码贴出来再说，不要顺手重构；
- 若 `page-loading.js` 之类会阻塞新脚本加载顺序导致 `AnnounceText` 未定义 → 必须在兜底分支下也能正常显示文本（不能白屏）；
- 若发现别处也渲染公告正文（例如个人中心的公告块）→ 在报告里列出，按同一函数处理。
