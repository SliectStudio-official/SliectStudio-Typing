## 1. A 组：分段必须可无损回放（`public/typing-engine.js`）

| # | 要求 |
| --- | --- |
| A1 | 硬约束：存在**只含空白**的 `gaps`，使 `text === gaps[0] + segs[0] + gaps[1] + segs[1] + … + gaps[n]`。**行内空格不得丢失**；只允许丢弃段首/段尾处空白，且必须体现在 gaps |
| A2 | 断点落在空白上时二选一并保持一致：① 空白留上一段末尾（渲染时 trim 显示，但计数要算）；② 空白归入 gaps。**无论哪种 A1 必须成立** |
| A3 | `splitTextWithOffsets` 的匹配循环**禁止盲推兜底**：`text.startsWith(segment, cursor)` 不成立时 → `console.error`（段号/段内容/游标）+ 从游标按 maxLen 重新硬切后继续，**绝不允许 `cursor += segment.length` 静默推进** |
| A4 | 新增内部 `verifySegments(text, segments, offsets) → { ok, reason }`：校验 A1 与空隙纯空白；在 `splitTextWithOffsets` 末尾调用，失败只 `console.error` 一次（不要每次输入都刷） |
| A5 | 两个导出函数返回形状不变；P16 的分段优先级、开括号/收尾标点约束、英文不断词、`minLen` 规则、`measureMaxLen` 取宽逻辑全部保留 |
| A6 | `splitOversizedSegments` 同样必须满足 A1 |

## 4. D 组：匹配底栏重做（`public/nav.js` 标记 + `public/style.css`）

### 根因
`.race-match-bar { background: var(--ink); color: #fff }` —— **拿文字色令牌当背景**。`--ink` 亮色主题 `#141413`、暗色主题 `#e8e6e0`，于是暗色下变成"浅底白字"。

### 要求

| # | 要求 |
| --- | --- |
| D1 | 背景改表面令牌：`background: var(--glass-bg)`、`color: var(--ink)`、`border-top: 1px solid var(--hairline-soft)`、`box-shadow: var(--glass-shadow)`、`backdrop-filter: blur(var(--glass-blur))`（含 `-webkit-`） |
| D2 | 布局改**居中**：`display:flex; align-items:center; justify-content:center; gap:10px` ——「时间 + 关闭图标」作为一组整体水平居中 |
| D3 | 时间 `font-weight: 700`、`font-variant-numeric: tabular-nums`、颜色 `var(--ink)` |
| D4 | 关闭按钮：26×26 圆形、`border: 1px solid var(--hairline-strong)`、透明底、`color: var(--body-strong)`、hover 用 `--glass-bg-hover` + `--ink`；内含 SVG 14×14、`stroke: currentColor` |
| D5 | **禁写死颜色**：本组选择器内不得出现 `#fff` / `#000` 作背景或文字（`--on-primary` 缺失时可用 `#fff` 兜底并说明） |
| D6 | 底栏高度由脚本写入：`document.body.style.setProperty('--race-match-bar-h', bar.offsetHeight + 'px')`；`body.race-match-open { padding-bottom: var(--race-match-bar-h, 54px) }` |
| D7 | 420px：内边距收紧、字号 12.5px、关闭按钮不小于 24×24 |
| D8 | 标记改为：`<div class="race-match-bar" id="race-match-bar"><span class="race-match-bar-text" id="race-match-bar-text"></span><button class="race-match-bar-close" id="race-match-bar-action" aria-label="取消匹配" title="取消匹配"><svg viewBox="0 0 16 16" fill="none" stroke-width="1.6" stroke-linecap="round"><path d="M4 4l8 8M12 4l-8 8"/></svg></button></div>` |
| D9 | **不得再往按钮写文字**：现有 `action.textContent = …` 会抹掉 SVG，改为只更新 `aria-label` / `title` |
| D10 | 三态：① 等待「匹配中 mm:ss」+ 关闭图标；② 匹配成功且自动跳转「匹配成功，正在进入比赛…」（无按钮）；③ 匹配成功但用户在练习中「匹配成功」+ 主按钮「进入比赛」（`--primary` 系列）+ 关闭图标 |
| D11 | 键盘可达：Tab 聚焦关闭按钮、Enter/Space 触发；`Esc` 不取消匹配（避免误操作） |
| D12 | 保留原行为：取消 → `/api/race/match/cancel`、清 `raceMatchPending`、收起底栏、移除 `body.race-match-open` |
