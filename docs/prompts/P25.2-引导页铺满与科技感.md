# P25.2-引导页铺满全屏 + 尺度对齐主站 + 动画与科技感

> 读的提示词就是本文件。开工时算本文件 sha256，写进执行报告第一行。
> 用户原话一：「**让页面能填充满网页 动画效果太少 要有科技感**」
> 用户原话三：「**布局还是要是我设计的三个按钮纵向排列啊 不允许横向**」
> 用户原话二：「**而且图标，文字这些太大了 不匹配主页面的大小，沿用主页面的文字大小图标大小等 设计还是采用我的**」
> 只改**引导页**（`public/home.html` / `home.js` / 相关 `.dash-*` 与新增 `.fx-*` 样式）。练习页 `index.html` 与 `script.js` **一行都不许动**。

## 0. 先解决一个取舍（重要）

现在引导页是 1920×1080 固定画布等比缩放（`s = min(w/1920, h/1080)`）。这个做法在**任何非 16:9 的屏幕上都必然留黑边**：1440×900 上下各 45px、1280×800 上下各 40px —— 这就是你说的"填不满"。

**等比缩放与铺满不可兼得**。本批按"铺满"来：

| 层 | 做法 |
| --- | --- |
| 背景照片 | 全视口 `position: fixed; inset: 0` + `object-fit: cover`，**永远铺满、无黑边**，并加缓慢 Ken Burns 缓慢推近 |
| 内容层 | **不再 transform 缩放**，改成真弹性布局：左右边距、三卡宽度、资料卡宽度、卡片高度都用 `clamp()` 按视口比例伸缩，等比关系照设计稿 |
| 竖屏 / 宽 <900 | 仍旧转垂直列表（这条不变） |

> 若你更想保留"整体等比缩放"的观感，替代方案是背景 cover 铺满 + 内容按 `min` 缩放居中 —— 但内容会在大屏上显小、两侧仍空。**默认按上表做**，报告里注明这条取舍。

## 1. 铺满：具体数值（**三张卡必须纵向排列，禁止横向**）

> 设计稿原样：`.actions` 在**左栏**，宽 425px，三张卡 `.action-card` **各 425×100、纵向依次排列、间距 15px**（设计稿注释：节点 4:51，425×100，间距 15）。
> **上一版我写成"一行三张"，这是错的，本版纠正**：三卡永远是**单列纵向**，任何视口都不许横向并排。

| # | 元素 | 规格 |
| --- | --- | --- |
| F1 | 页面结构 | 左右两栏：**左栏** = 欢迎语 → 用户名 → 三张动作卡（纵向）→ 版本号；**右栏** = 资料卡。`grid-template-columns: minmax(0,1fr) auto`，左右边距 `clamp(24px, 4.7vw, 72px)` |
| F2 | 欢迎语与用户名 | 字号固定：欢迎语 14px、用户名 22px（见 §1.5，**不随视口缩放**） |
| F3 | **三张动作卡（纵向单列）** | 容器宽 `clamp(280px, 22vw, 425px)`（设计稿 425px）；三张卡 `display:block` 单列排布，**每张宽度 100% 容器**，卡间距 `clamp(10px, 1vw, 15px)`，卡高 `clamp(72px, 9vh, 96px)`；**禁止** `grid-template-columns: repeat(3, …)`、`display:flex` 横排、`float` 等任何横向并排写法 |
| F4 | 资料卡 | 宽度 `clamp(260px, 18vw, 320px)`，高度自适应，位置在右栏、与左栏三卡同一纵向区间 |

| F6 | 底部匹配状态条 | 贴底 `position: fixed; bottom: 0`，宽 100%，滑入动画（保留现有行为） |
| F7 | 禁止 | 三卡横向并排（**这条是用户明确要求**）；任何纯色大块留白；`scrollWidth > clientWidth`；内容被裁切 |

## 1.5 尺度统一：字号与图标一律沿用主站（用户第二条要求）

> 用户原话：「图标、文字这些太大了，不匹配主页面的大小，**沿用主页面的文字大小、图标大小**，设计还是采用我的」。
> 也就是说：**布局与结构照设计稿，字号与图标尺寸照主站**。主站基准（我从 `public/style.css` 核过）：
> `body { font-size: 15px; line-height: 1.5 }`；`.section-card-title` = `16px × --heading-scale`、600；`h1/h2/h3` = 36/28/22 × `--heading-scale`；`.btn-primary` 内边距 `6px 14px`；`nav` 高 56px（窄屏 52px）；导航图标 18px、22px。

## 2. 动画与科技感（这是本批重点）

### 2.1 必须做的七项

| # | 效果 | 做法（GPU 友好：只用 transform / opacity / filter） |
| --- | --- | --- |
| A1 | **入场错峰淡入** | 欢迎语 → 用户名 → 三卡（每张 80ms 递增）→ 资料卡，`opacity 0→1` + `translateY(12px→0)`，单次总时长 ≤600ms |
| A2 | **背景缓慢推近（Ken Burns）** | 背景图 `scale(1.04→1.10)` 20s `alternate` 匀速循环，极缓；`will-change: transform` |
| A3 | **科技网格 / 扫描线叠层** | 纯 CSS：`repeating-linear-gradient` 细网格（1px 线、48px 间距、不透明度 ≤0.06）叠在照片上；可加一条 8s 循环的极淡横向扫描光带（不透明度 ≤0.05） |
| A4 | **卡片 hover 流光描边** | `conic-gradient` 旋转描边（`@property` 不可用时用两层伪元素 + `transform: rotate` 8s 线性），hover 时出现；描边宽度 1px |
| A5 | **卡片指针视差** | `mousemove` 时卡片按指针位置做 ±4px / ±2° 的轻微倾斜与高光跟随，`transition: 120ms`；触摸设备不启用 |
| A6 | **数字滚动** | 资料卡四项统计与版本号加载后从 0 递增到目标值（600ms，`ease-out`）；非数字（`—`）不参与 |
| A7 | **发光与呼吸** | 快速开始卡在 matching 态时边框做 2s 呼吸发光（`box-shadow` 用 `filter: drop-shadow` 或伪元素 opacity 呼吸，避免每帧重排）；标题前加一个 2px 品牌色光标，1s 闪烁 |

### 2.2 性能与克制（同样硬性）

| # | 要求 |
| --- | --- |
| P1 | 动画元素总数 ≤ **60**；禁止 `box-shadow` / `width` / `top` 这类触发重排的属性做持续动画 |
| P2 | **单 rAF 循环**驱动所有持续动画；`document.hidden` 时暂停，可见时恢复 |
| P3 | `@media (prefers-reduced-motion: reduce)` 下**全部关闭**（不留过渡残留） |
| P4 | 首屏动画不得阻塞交互：任何卡片在动画未结束时也可点击 |
| P5 | 生产环境目标：引导页空闲时 CPU ≤ 5%、滚动/缩放不掉帧（贴 rAF 间隔 P95） |
| P6 | 不引入任何第三方库、不下载字体、不新增图片资源（网格/扫描线/流光全部用 CSS） |

### 2.3 科技感的视觉约束

| # | 要求 |
| --- | --- |
| V1 | 主色仍用现有品牌橙（`--primary` 系）与玻璃令牌，**不要**改成霓虹青紫那种整体换色；科技感靠**网格、光扫、流体描边、数字滚动、发光**这些细节，不靠改配色 |
| V2 | 所有新增透明度效果叠加后，正文与说明文字对比度仍须 ≥ 4.5:1 / ≥ 3:1（贴计算值） |
| V3 | 网格与光扫的叠层必须 `pointer-events: none`，不得挡住三卡点击 |
| V4 | 动画节奏克制：入场一次性、持续动画只有背景推近与匹配态呼吸，其余靠 hover —— **不要**满屏乱动 |

## 6. 停止点

- 若"铺满"必须裁掉内容才能做到（例如超宽屏资料卡被挤出）→ **停**，给我两档截图（裁内容 / 留少量边）我选；
- 若指针视差在触摸设备或低端机上造成掉帧 → **停**，直接砍掉这一项，不要凑合；
- 若网格/扫描线让背景照片发脏（对比度或观感变差）→ **停**，给"有叠层/无叠层"两张图我选；
- 若为了让页面"填满"而想把三卡改成横向 → **停**：**用户明确不允许横向**，填满只能靠留白、卡片宽度与背景实现；
- 若把字号压到主站尺度后，设计稿的版面比例明显变形（例如三卡变得又宽又扁）→ **停**，给我"字号照主站 / 版面比例照设计稿"两个折中方案（可适当上调卡片高度与间距，但**字号不许放大**）；
- 若必须改 `script.js` 或 `index.html` 才能实现 → **停**，说明原因。
