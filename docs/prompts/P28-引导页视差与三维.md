# P28-引导页指针/陀螺仪视差与三维层次

> 读的提示词就是本文件。开工时算本文件 sha256，写进执行报告第一行。
> 你是执行方 AI。**只改引导页**（`public/home.html` / `home.js` / `style.css` 的 `.dash-*` 与新增 `.fx-3d-*`）；练习页、比赛页、服务端一律不动。
> 用户原话：「**要求主页的背景加入随鼠标移动的视差，移动端读取陀螺仪，并且界面也可以这样 甚至做成三维的界面**」

## 0. 要做成什么样

| # | 要求 |
| --- | --- |
| 1 | **背景视差（桌面）**：鼠标在页面移动时，背景各层按不同"深度"做极小幅度位移（照片层最大、网格层中等、压暗层不动），营造纵深 |
| 2 | **陀螺仪视差（移动端）**：`DeviceOrientationEvent` 的 `beta/gamma` 映射成同样的位移；iOS 13+ 需要 `requestPermission()`，**必须由用户手势触发**，拒绝或不可用时**静默降级为静态** |
| 3 | **界面也参与**：内容层（欢迎语/用户名/三张卡/资料卡）在鼠标移动时做**极轻微**的三维倾斜（`rotateX/rotateY` ≤1.5°），卡片再叠加各自的 `translateZ` 形成层次 |
| 4 | **三维感**：整块用 `perspective` 建立景深，元素按 `translateZ` 分层（背景 0 / 网格 +10px / 卡片 +30px / 资料卡 +40px），移动时有真实的前后错动 |
| 5 | **克制**：所有位移 ≤16px、所有旋转 ≤3°；鼠标停下 400ms 后缓回原位；不得有晕动感 |
| 6 | **必须可关**：`@media (prefers-reduced-motion: reduce)` 下全部关掉（静态居中）；`body.fx-paused`（页面隐藏）时暂停 |

## 1. 实现规格

| # | 项 | 做法 |
| --- | --- | --- |
| A1 | 单一指针源 | 维护 `state.pointer = {x: -1..1, y: -1..1}`：桌面取 `mousemove`（相对视口中心归一化），移动端取陀螺仪。**一处产生、多处消费**，不许每个元素各绑一份事件 |
| A2 | 阻尼平滑 | 用单个 rAF 循环做 lerp（阻尼系数 0.08–0.12）逼近目标值，收到值后写 CSS 变量：`--px`、`--py`（-1..1）。**禁止**每次 `mousemove` 直接改 `style.transform`（会抖） |
| A3 | 图层分工 | 背景照片：`translate3d(var(--px)*16px, var(--py)*12px, 0)`；网格层：×0.6；压暗层与渐变层：不动；内容层：`rotateX(var(--py)*-1.2deg) rotateY(var(--px)*1.2deg)`；资料卡：额外 `translateZ(40px)` + 反向位移 ×0.4（视差相反，更像 3D） |
| A4 | 景深 | 容器 `perspective: 1400px; transform-style: preserve-3d`；各层 `translateZ` 按 §0 第 4 条 |
| A5 | 陀螺仪 | `window.addEventListener("deviceorientation", handler)`；`gamma`（左右，-90..90）→ `x`、`beta`（前后，-180..180）→ `y`，各自 `clamp` 到 ±30° 再归一到 -1..1；无数据或全 0 视为不可用 |
| A6 | iOS 授权 | 检测 `typeof DeviceOrientationEvent.requestPermission === "function"`：**不自动弹**，在引导页右下角放一个 16×16 的极淡提示点（或首次 `touchstart` 时调用一次）；拒绝后**永久降级**，不再请求 |
| A7 | 暂停与销毁 | `visibilitychange` 隐藏时停 rAF；`prefers-reduced-motion` 时不启动任何监听（连事件都不绑） |
| A8 | 与既有卡片视差的关系 | 现在卡片已有 `--fx-tx/--fx-ty/--fx-rx/--fx-ry`（±4px/±2°）。本批把它们**并入同一指针源**：卡片倾斜 = `pointer` 的局部放大（保持 ±2° 上限），不得出现两套互不相关的位移 |
| A9 | 性能 | 每帧最多写 **8 个**元素的 CSS 变量/transform；`will-change: transform` 只给三层；`backdrop-filter` 元素（P25.3 的 9 个）**不得**跟随旋转（旋转会让模糊重采样、掉帧）——只允许平移，或干脆不动 |
| A10 | 文字清晰 | 旋转角度这么小不至于糊；但**禁止**对含文字的层用大角度 3D 或 `translateZ` 大于 40px，避免亚像素模糊 |

## 2. 验收（逐条贴读数）

| # | 场景 | 判据 |
| --- | --- | --- |
| 1 | 鼠标视差 | 鼠标移到左上角与右下角各停 300ms，贴三层元素的 `transform` 矩阵（照片层位移应为 **±(16,12)px 以内**、网格层约为其 60%、压暗层**不变**） |
| 2 | 幅度上限 | 贴任意时刻最大位移与最大角度：位移 **≤16px**、旋转 **≤3°**（内容层 ≤1.5°） |
| 3 | 平滑不抖 | 快速甩鼠标 1 秒后立即取样与 200ms 后再取样，两次值不同且单调收敛（贴两组 `--px/--py`）；控制台无抖动告警 |
| 4 | 3D 层次 | 贴 `perspective` 与各层 `translateZ` 计算值（0 / 10 / 30 / 40px）；移动时资料卡与卡片的相对位移方向相反（贴两张卡的 `transform` 对比） |
| 5 | 陀螺仪 | 用设备或 DevTools 的 sensor 模拟：`gamma` 从 -30 → +30 时 `--px` 从 -1 → +1（贴映射前后的读数）；`beta` 同理 |
| 6 | iOS 授权降级 | 模拟 `requestPermission` 返回 `denied`：页面**无任何报错**、视差静止、其余交互正常（贴控制台读数） |
| 7 | 无传感器降级 | 模拟无 `deviceorientation` 事件：桌面鼠标视差仍工作；纯触屏无陀螺仪时页面静止、不报错 |
| 8 | 减弱动效 | `prefers-reduced-motion: reduce` 下：**不绑定任何监听**（贴断点/监听计数为 0），元素 `transform` 为 none |
| 9 | 暂停 | 切到后台 3 秒再回来：无 CPU 占用（贴 `requestAnimationFrame` 回调次数在隐藏期间为 0） |
| 10 | 性能 | 移动鼠标 5 秒：rAF 帧间隔 **P95 ≤16.7ms**；贴 `backdrop-filter` 元素数（应仍为 9）与其 `transform`（只平移或 none） |
| 11 | 与卡片视差同源 | 鼠标移到卡片左下：卡片 `--fx-tx/--fx-ty` 与背景 `--px/--py` 方向一致；贴两组值证明 |
| 12 | 回归 | 纵向三卡（rect left 相同）、铺满无黑边、字号 16/22/14/20/12、模糊 `blur(20px) saturate(1.1)`、匹配态蓝 `rgba(68,74,255,.2)`、扫光只在匹配时——各贴一条读数 |

## 4. 停止点

- 若为了做"真三维"需要引入 three.js / WebGL → **停**：本批只做 CSS 3D 视差；真三维另立批次（要先谈体积与兼容性）；
- 若旋转让玻璃模糊重采样、P95 超 16.7ms → **停**：把跟随旋转的元素限定为不含 `backdrop-filter` 的层，报告里说明取舍；
- 若陀螺仪在 Android 上与桌面鼠标事件冲突（同一 `pointer` 变量被两边覆盖）→ **停**：按"输入源互斥"实现（触摸设备只用陀螺仪，有鼠标才用鼠标），报告里写明判定条件；
- 若 `prefers-reduced-motion` 下仍需绑定监听才能判断 → **停**：用 `matchMedia` 提前判断，别先绑后停。
