# 架构

> 依据：源码里的结构定义与本次建盘时的实测读码。只写已经确认的部分；没有代码支撑的写「未建立」。
> 图与代码冲突时改图；能用命令验证的依赖以命令输出为准。

## 一、分层与依赖方向

| 层 | 位置 | 职责 | 依赖方向 |
| --- | --- | --- | --- |
| L1 静态资源层 | `public/`（由 `express.static` 提供，HTML 先经引用重写中间件） | HTML/CSS/JS/图标/头像；js/css 内容指纹作为 `?v=` 参数写进 HTML，指纹表由 `GET /api/asset-version` 暴露；Service Worker 的缓存名从该端点派生；`/service-worker.js` 由服务端在响应时注入 `// asset-version: <版本>` 首行，使资源变化能触发 SW 更新 | 只被浏览器消费 |
| L2 HTTP 路由层 | `server.js`（1680 行，62 个端点） | 参数校验、业务逻辑、响应组装 | 只能向下依赖 L3、L4 |
| L3 鉴权中间件 | `server.js` 内 `authMiddleware` / `adminMiddleware` | 校验 Bearer token，按 id 回查 `users` 取 role，再判权限 | 依赖 jsonwebtoken 与 L5 的只读查询（每次受保护请求一次主键查询） |
| L4 数据适配层 | `db-config.js`（604 行） | 方言差异隔离：统一的 get / all / run / exec / transaction / getTables / getColumns / getPrimaryKey | 只依赖 better-sqlite3 或 mysql2 |
| L5 存储 | `data/typing.db`（SQLite，WAL）或 MySQL `typing` 库 | 持久化 | — |

允许的方向：L1 ← 浏览器；L2 → L3、L2 → L4 → L5、L3 → L5（只读 `users` 取 role）。禁止：L4 反向依赖 L2；L3 除取 role 外不得直接读写 L5，也不得承载业务规则。

## 三、数据适配层的双分支

`createDatabase(config)` 按 `db-config.json` 的 `type` 返回同一形状的对象；调用方（`server.js`）不感知方言。差异集中在四处：

1. 时间函数：`nowLocaltime` / `curDate` / `dateFn` / `daysAgo` 返回方言 SQL 片段，禁止在路由里手写时间函数。
2. 分页与长度函数：`CHAR_LENGTH` vs `LENGTH`、`SUBSTRING` vs `SUBSTR`，路由层已用 `isMySQL(db)` 分支处理。
3. 事务：MySQL 分支把连接对象作为第一个参数传给回调，SQLite 分支**没有传**，导致三个事务端点 500（坑库 K-01）。
4. 元数据：`getTables` / `getColumns` / `getPrimaryKey` 各自实现，SQLite 走 PRAGMA，MySQL 走 INFORMATION_SCHEMA。

改任一侧都必须对称检查另一侧，这是本项目的固定成本。

## 四、前端结构

| 页面 | 脚本 | 职责 |
| --- | --- | --- |
| `index.html` | `script.js`（1442 行） | 练习、排行、投稿、私人文章、离线文章入口 |
| `admin.html` | `admin.js`（2160 行） | 仪表盘、用户、文章、分类、公告、数据库面板、抓取 |
| `profile.html` | `profile.js`（908 行） | 个人资料、历史、统计、错字、投稿记录 |
| `setup.html` | 内联 | 首次初始化管理员 |

共享脚本：`theme-toggle.js`、`custom-select.js`、`loading-indicator.js`。`service-worker.js` 负责静态资源缓存与 IndexedDB 离线文章（缓存名 `typing-practice-v7`）。

鉴权载体：token 存 `localStorage`，请求头带 `Authorization: Bearer`。前端认为能力边界由服务端 API 决定，页面本身不做权限拦截（`admin.html` 静态可达，数据接口有 admin 校验）。

## 五、外部进程

`crawler.py` 由 `server.js` 用 `execFile('python', ...)` 调用：抓取单页 90 秒超时、搜索 45 秒超时，stdout 返回 JSON、stderr 只取末 3 行。Python 依赖见 `requirements.txt`（requests / beautifulsoup4 / chardet）。
