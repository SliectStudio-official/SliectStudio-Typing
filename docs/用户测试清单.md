# 用户测试清单（普通用户版）

> 怎么用：从上往下做一遍。**能做下去、看得懂、不卡住**就算通过；哪一步让你困惑或者看到奇怪的东西，记到最后那张反馈表里发回给我们。
> 预计 25–35 分钟。不用懂技术，也不用改任何设置。

## 开始前（问管理员要这些）

| # | 准备 |
| --- | --- |
| 1 | 站点地址（形如 `http://192.168.x.x:3000`）与一个测试账号 |
| 2 | 浏览器用 Chrome 或 Edge 的最新版 |
| 3 | **两台设备**（电脑 + 手机，或两台电脑）——比赛部分要两个人同时在线 |
| 4 | 如果找不到入口，先在服务器那台机器上打开 `http://localhost:3000/setup.html` 创建管理员（只能在那台机器上做） |

## 标注（测试前请先看这一段）

### 这份清单是干什么的

这是**给普通用户**的体验测试清单，目的是找出「新人第一次用会不会卡住、会不会看不懂」。它不测代码、不测性能，只需要你像平时使用软件一样走一遍，把不顺的地方记下来。

### 下面这些是**已知情况，不算问题**，不用报

| # | 已知情况 | 说明 |
| --- | --- | --- |
| 1 | 「首次创建管理员」只能在服务器那台机器上做 | 用 `http://localhost:3000/setup.html`；在别的电脑上点「创建」会提示只能本机操作，这是防止别人抢先占管理员，属于正常设计 |
| 2 | 浏览器标签页图标在部分浏览器里可能不显示 | 不影响使用；换成 Chrome / Edge 一般就有 |
| 3 | 网络不稳时会提示「连接中断，正在重试…」 | 这是正常提示，网络恢复后会自动继续 |
| 4 | 参赛人数很多（几十人）时，别人的进度大约 3 秒更新一次 | 不是卡，是故意的省流量设计 |
| 5 | 断线超过 1 分钟会被当成掉线 | 房间里的解散投票规则会因此变化，属正常 |
| 6 | 手机第一次打开可能比电脑慢一两秒 | 属正常加载 |

### 请不要做的事

| # | 不要做 |
| --- | --- |
| 1 | 不要修改或删除别人的文章、公告、用户（这是共用的测试环境） |
| 2 | 不要把管理员密码改成自己记不住的东西 |
| 3 | 不要用同一个账号在两个标签页里同时打同一局（会互相打断，不是 bug） |
| 4 | 不要为了测试反复刷新正在进行的比赛（会把你自己判成掉线） |

### 怎么把结果给我们

1. 把这份清单里打勾的部分确认一遍，未通过的行填「备注」；
2. 反馈表按「编号 + 做了什么 + 实际看到什么 + 期望什么 + 严重度」填，**最好带一张截图**；
3. 一次反馈一批就行，不用边测边发；
4. 有「卡住」级别的问题（做不下去）请立刻告诉我们，不用等全部测完。

### 测完请回答一句

> **「如果这是给同事用的正式系统，你敢不敢直接推给他们用？」** 敢 / 不敢 + 一句原因。这句比所有条目都重要。
