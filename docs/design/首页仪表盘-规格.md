## 四、与现有实现的差异（gap 清单）

| # | 设计稿要求 | 现状 | 结论 |
| --- | --- | --- | --- |
| G1 | 首页改成"仪表盘"：欢迎区 + 三个动作卡 + 右侧资料面板 | 现在是「选文章 → 开始练习」的传统表单页 | **页面级重做** |
| G2 | 「继续上次的练习」 | 无此能力（不记上次练习的文章与进度） | **新功能**：需要持久化"上次练习" |
| G3 | 「快速开始 / 进行 SOLO 匹配」 | 规划中（P18 快速匹配），未实现 | 新功能，依赖 P18 |
| G4 | 「加入比赛房间」 | 已有 race.html 大厅 | 只需跳转 |
| G5 | 统计含**胜率** | `/api/user/stats` 只给练习次数/字数/时长 | **需新增聚合**（从 `race_participants` 算） |
| G6 | 字号体系 48/32/24/20/15 | 现有 22/20/16/15 | 需新增 48、32、24 三档 |
| G7 | 字体 **OPPO Sans 4.0** | 系统字体栈（刚去掉衬线） | Windows 默认没有该字体 → 需回退栈或引 Web 字体（白名单外） |
| G8 | 玻璃卡 #fff 10% + 1px #fff 描边 + 圆角 15/20 | 现有 `--glass-bg` / `--hairline-*` / 12–14px 圆角 | 需补充"深色玻璃"令牌 |
| G9 | 背景照片 + 右侧黑渐变 | 现有为纯色/渐变 canvas | 需背景资源（体积与发布包策略要定） |
| G10 | 只有 1920 一个画板 | 现有 3 档断点 | **缺 1440 / 1024 / 768 / 420 与移动版** |

## 五、必须由设计/用户补齐的缺口

1. **断点**：1440 / 1024 / 768 / 420 四个尺寸的排布（否则我只能自己拍降级规则）；
2. **状态**：三个动作卡的 hover / active / disabled、头像与链接的 hover、统计加载中与空态、退出确认弹窗；
3. **资源**：背景照片是否要给（多大、能否压缩到 200KB 内）、三个图标与四个箭头是否可用 SVG 导出、头像占位规则（我们已有"纯色+首字"）；
4. **数据口径**：胜率怎么算（只算 1v1？含多人局？未完赛算不算）；平均速度是"字/分"还是"击键/分"；累计字数用字符数还是非空白字符数；
5. **"继续上次的练习"** 的语义：记文章+位置？还是只记文章？换设备是否延续（要落库还是仅本机）；
6. **字体**：是否接受用系统字体回退（OPPO Sans 仅其品牌机自带），还是要引 Web 字体（体积 + 白名单外依赖，需报批）。
