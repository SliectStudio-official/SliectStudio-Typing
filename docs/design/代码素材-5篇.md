## 1. JS-数组求和（JavaScript，115 字符）

```js
const nums = [1, 2, 3, 4];
const total = nums.reduce((a, b) => a + b, 0);
console.log(total > 5 ? "big" : "small");
```

## 2. JS-函数与默认值（JavaScript，122 字符）

```js
function greet(user) {
  const name = user.name || "guest";
  return "hi, " + name;
}
console.log(greet({ name: "Amy" }));
```

## 3. PY-字典排序取前二（Python，157 字符）

```python
def top_items(prices):
  items = sorted(prices.items(), key=lambda kv: -kv[1])
  return [k for k, v in items[:2]]

print(top_items({"a": 3, "b": 9, "c": 5}))
```

## 4. PY-逐行解析带异常（Python，176 字符）

```python
def parse_all(lines):
  out = []
  for line in lines:
    try:
      out.append(int(line))
    except ValueError:
      continue
  return out

print(parse_all(["1", "x", "3"]))
```

## 5. SQL-按速度分组取名次（SQL，171 字符）

```sql
SELECT u.name, CASE WHEN s.speed >= 200 THEN "fast" ELSE "slow" END AS lvl
FROM scores s JOIN users u ON u.id = s.user_id
WHERE s.speed > 0
ORDER BY s.speed DESC
LIMIT 10;
```
