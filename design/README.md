# design/ — 设计稿还原（预览用，非生产代码）

本目录只用于「看稿」：把 Figma 设计稿还原成静态 HTML，浏览器打开即可对照，
「快速开始」可以点一下进入正在匹配状态、再点取消。
**没有接入 server.js、没有改动 public/ 下任何文件**，不属于运行时代码，也不进发布包。

## 怎么打开

直接双击 `index.html`（file:// 即可，无需起服务）。页面是固定 1920×1080 画布，
按窗口等比缩放居中，任何屏幕上看到的都是同一张稿。

## 能点的交互

| 动作 | 结果 |
| --- | --- |
| 点「快速开始」 | 切到正在匹配状态：卡片变蓝色 `#444aff` 20%、标题变**正计时**（从 `00:00` 起累计已等待时长）、副文案变队列信息、右侧箭头换成 ×；底部状态条自下而上滑入 |
| 匹配中再点整张卡片 | 取消匹配，卡片与状态条一起复位 |
| 点状态条右侧 × | 同样取消匹配 |

计时是**正计时**，不是倒计时：设计稿那帧的 `00:15` 是「已等待 15 秒」，所以从 `00:00` 起往上走，
卡片标题与状态条计时同步，取消后重新开始归零重计。**匹配成功的判定与「进入练习页」没有做**
（代码里标了 `NOT IMPLEMENTED`，需要后端接口），所以计时会一直走下去。

## 与设计稿的已知偏差

| # | 偏差 | 原因 / 影响 |
| --- | --- | --- |
| D1 | 字体用回退栈（微软雅黑 → system-ui），不是 OPPO Sans 4.0 | Windows 默认没有该字库；字宽略宽，字重节奏一致。要 1:1 需字体文件或批准引 Web 字体 |
| D2 | 背景照片以 jpg 导出 | 视觉一致，仅编码损失；发布若要用需评估体积与版权 |
| D3 | 统计文字节点上的 `stroke`（align=OUTSIDE，渐变几乎全透明）未还原 | 渲染上不可见；若设计本意要描边需确认 |
| D4 | hover 态是我加的（普通卡提亮到 9%，匹配中卡片提亮到 28%） | 设计稿没有交互态，仅为可点反馈 |
| D5 | 文案是设计稿占位数据（UserName / 5.67 K / 235.7 M / 200 / 75% / 前方队列 1 人） | 静态稿，不连后端 |
| D6 | 状态条出现动画（自下而上 75px 滑入 + 淡入，320ms `cubic-bezier(.22,.8,.2,1)`）是我定的 | 设计稿没有动效标注，要改时长/缓动/方向直接改 `.status-bar` 的 transition |
| D7 | 计时是正计时（累计已等待），卡片标题与状态条同步、取消后归零 | 设计稿只给静态两帧（`00:15` = 已等 15 秒），正计时口径由用户 2026-11-07 确认 |
