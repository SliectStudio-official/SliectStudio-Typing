## 3.5.261108.0326（2026-11-08）

**一句话**：修掉两个影响比赛的硬问题，并让服务在面板托管下更耐造。

### 修好了

| 症状 | 现在 |
| --- | --- |
| 比赛打到 **90%** 打字区整块消失、之后按键没反应 | 已修：进度条过了 90% 也不会再丢打字区，可以正常打完、正常结算 |
| 管理页偶发「改不了 / 删不了 / Failed to fetch」 | 已修：管理接口不再被浏览器离线缓存“假装在线”，断线会明确提示「与服务器的连接已断开」 |
| 服务被面板托管时偶尔“炸掉” | 已修：管道断开不再让进程退出；启动失败会打印中文原因（如端口被占用） |
| 服务换了端口后，旧页面还在打老端口 | 已修：页面会提示「检测到 :3000 有服务，点此继续」，点一下自动跳过去 |
| 匹配抽文时卡片大小不统一、定格后文案还写着“正在抽取” | 已修：抽取过程中所有卡一样大，**抽完只有中奖卡放大并居中**，文案改成「已抽中：<文章名>」 |

### 用起来不一样的地方

- 启动时的黑窗口 / 面板日志会多打印「监听地址、数据库文件、数据目录、页面根目录」，出问题时一眼能看出跑的是哪个库、哪个端口。

### 升级须知

- **必须重启**（本版改了 `server.js`）。
- 只覆盖程序文件，**不要动 `data\`**；`data\` 里是你的用户、文章、成绩。
- 覆盖后浏览器按一次 `Ctrl+F5`。

## 3.4.261108.0131（2026-11-08）

**一句话**：代码练习上线，比赛与管理面板跟着改造。

- 练习页新增「代码模式」：像代码编辑器一样打字（原文渐隐、Tab 自动缩进、回车换行、禁止粘贴、手机上自动禁用）。
- 比赛可以打代码素材了：建房先选「普通房间 / 代码房间」，快速匹配多了一个「允许匹配代码素材」开关；代码局在用代码输入框，和练习页手感一致。
- 新增「代码榜」：代码成绩单独成榜，不混进总榜。
- 管理面板分成「普通模式管理 / 代码模式管理」两块：代码素材、语言分类、代码榜各自独立管理；编辑代码素材时正文是等宽代码框。
- 比赛大厅打磨：房间码一键复制、自己的最近战绩一排展示、房间列表显示「代码」标记、自动刷新、手机上按钮更大。
- 引导页：没有公告时顶部通知条自动收起，只留右上角一个铃铛。

**升级须知**：必须重启；**非开发机的库**要跑一次代码分类迁移（`node docs\migrate\P35.2-代码分类迁移.cjs` 或面板里 5 步）。

## 附：写请求为什么都用 POST（自下一版起生效）

从 `3.6` 起，管理页与其它页面的**写请求全部改用 `POST` 发送**，并在请求头带 `x-http-method-override: PUT|DELETE`，服务端按原方法执行。

| 项 | 说明 |
| --- | --- |
| 为什么要这么做 | 部分环境（安全软件的 Web 防护、某些代理）会**直接重置 `PUT` / `DELETE` 请求**，表现是页面一直报 `Failed to fetch`，但服务端日志里什么也没有、用 `curl` 打却正常。改成 POST 后这类环境也能正常用 |
| 对使用者有影响吗 | **没有**。功能、权限、返回结果、报错文案都不变 |
| 日志看得懂吗 | 看得懂。服务端在收到覆盖头后会把方法还原，日志里显示的仍是 `PUT` / `DELETE` |
| 上传文件受影响吗 | 不受影响。备份上传本来就走 `POST` + `multipart`，这次没动 |
| 排查时要注意 | 如果你在浏览器 Network 面板里看到写操作的 **Method 是 POST**，而路径像是“应该用 PUT 的”，那是正常的——看请求头里的 `x-http-method-override` 就知道真实方法 |
